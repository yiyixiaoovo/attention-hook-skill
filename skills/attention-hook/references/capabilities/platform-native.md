# 平台原生：先按平台的硬参数改，再谈创意

## R — 原文

> It makes sense without the second line (the "more" fold eats line 2+).
> — platform-native-2026.txt（MIT）

**这张卡不是证据卡。** 平台参数是工程事实（尺寸、折叠位、字数），效果判断仍要回到 `video-metrics` 或自有 A/B。参数会随平台版本变化，发布前必须核对官方文档。

## I — 方法论骨架

同一个开头，换个平台就要重写。先看平台给的**硬约束**，再动文案：

| 平台 | 硬约束 | 开头要满足什么 |
|---|---|---|
| 小红书 | 封面 3:4（1080×1440）；正文页标题 12–30 字；一组 1 封面 + 4–8 页 | 封面大标题能在一眼内读完；第一页给结果或冲突，不是背景 |
| 抖音 | 竖屏 9:16；前 3 秒定去留 | 3 秒内出现结果/画面/问题，不铺垫 |
| Instagram | 首行约 125 字符折叠；轮播逐页 | 第一行独立成立，第二行被折叠吃掉也不影响理解 |
| X | 280 加权字符；时间线只露前几行 | 第一句独立成立；引用帖第一句要能脱离原帖 |
| 公众号 | 封面 21:9 + 1:1 成对 | 两个比例各写各的标题，不互相复制 |

三条操作：

1. **先查折叠位**：这个词/这句话会不会被平台的「更多」截断？截断后还成立吗？
2. **按平台重写第一句**，不是缩放同一句：小红书要「一眼读完的结果」，IG 要「独立成立的第一行」，X 要「能脱离上下文的断言」。
3. **字数与页数当预算**：把平台的字符/页数上限当成注意力预算来分配，而不是写完了再删。

## A1 — 书中的应用

本卡没有可引用的叙事案例；平台参数来自公开规格与开源技能合集（见来源）。

合成演练（非语料案例）：一条「AI 帮我 3 小时做完周报」的内容。小红书版：封面大标题「3 小时周报→20 分钟」，底部 3 个要点，正文 6 页每页 12–30 字；抖音版：前 3 秒直接放计时器对比；IG 版：首行「我把周报压到 20 分钟」并保证第二行被折叠也不影响理解；X 版：第一句「周报 3 小时是流程问题，不是效率问题」。该演练只演示改写流程，不产生效果证据。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `packaging`：那张卡管标题/封面/开场三件套的**通用原则**；本卡把它们落到**具体平台的数字**上。
- 与 `hook-craft`：那张卡打磨开头几句话的结构；本卡先告诉你开头的**长度与折叠预算**，再交给它打磨。
- 与 `distribution-first`：那张卡决定发哪个平台、优化打开还是转发；本卡在平台已定后改文案。
- 与 `x-playbook`：那张卡是 X 的运营打法（选题/承接/折叠位）；本卡是跨平台参数对照，含小红书/抖音/IG。
- 与 `video-metrics`：本卡不判断效果；平台参数对了不等于内容会火。

## E — 执行 (Execution)

**输入**
- 一条已有内容（标题/开头/正文）。
- 目标平台（可多个）。
- 该平台当前版本的字数/尺寸/折叠规则（查官方文档或后台发布页）。

**步骤**
1. 锁定平台与形态（图文/轮播/短视频/帖子）。完成标准：写清平台、形态、发布位置。
2. 查折叠位与字数上限。完成标准：写出具体数字（如 IG 125 字符、X 280、小红书页标题 12–30 字）。
3. 按平台重写第一句。完成标准：截断到折叠位后仍独立成立。
4. 分配篇幅：把页数/字数预算分给「钩子—证明—收尾」。完成标准：每一页/每一段都有明确功能。
5. 尺寸与安全区检查（图文/视频）。完成标准：封面比例、安全边距、字号在手机缩略图下可读。
6. 跨平台一致性检查：同一事实，各平台版本是否互相矛盾。完成标准：事实不变，表达按平台重写。

**分支**
- 只发一个平台 → 只做该平台的 1–5 步。
- 一稿多平台 → 先写「事实底稿」，再按平台各写一版；不要缩放同一句。
- 平台规则不明 → 去发布后台看当前限制，不要凭记忆写数字。
- 图文与视频同时做 → 封面与首帧各自重写，不要共用一张图。

**输出**
- 平台参数清单（数字）+ 各平台第一句 + 篇幅分配 + 尺寸检查结论。

**完成标准**
- 每个目标平台都有独立的开头与篇幅预算；折叠位截断后仍成立；参数来自当前版本；事实在各版本一致。

## B — 边界 (Boundary)

1. **证据等级：实践者（最低）。** 参数是公开规格/行业实践，不是实验结论；「按参数改就能提升」没有证据，效果回到度量。
2. **参数会漂移**：折叠字符数、标题上限、推荐尺寸都改过多次；本卡写的是 2026-11 的口径，发布前核对官方文档。
3. **只引事实、不搬表达**：小红书参数来自 AGPL 项目，本卡只提取数字与结构，未复制其表达；引用来源见 `source/platform-native-2026.txt`。
4. **合规**：不得用平台参数去规避审核、伪造互动或做「擦边」封面；这类操作违反平台规则。
5. **不承诺效果**：参数正确只保证「不被折叠吃掉/不被裁掉」，不保证点击或转化。
