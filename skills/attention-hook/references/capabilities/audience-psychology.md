# 受众心理：从「一条内容」到「一群会回来的人」

## R — 原文

> I've spent years studying how to use psychology to build cult audiences that keep coming back.
> — kallaway-transcripts-2026.txt（practitioner）

**这张卡不是证据卡，也是本套技能里伦理风险最高的一张。** 全部内容来自一位创作者的经验；没有任何实验支持；B 段写死了不能做什么。

## I — 方法论骨架

目标不是单条爆款，而是**让人回来**。四个操作（按原文可提取的部分）：

1. **立场要明确、可讨论**：内容要有一个能让人赞成或反对的立场，模糊的"客观分析"不会引发参与。原文的说法是"ratchet up your stance"（把立场一点点加码）。
2. **绑到已被讨论的符号上**：围绕大家已经有看法的品牌、人物、观念、运动做选题——观众参与讨论的门槛最低。
3. **痴迷是分层的**：原文区分"痴迷等级"，并说第一层（level one obsession）最容易做——先让人对你产生轻度兴趣，再逐层加深，而不是一上来就要"死忠"。
4. **身份与地位感**：让观众在阅读/观看中获得某种身份确认或圈层归属（原文用 "king status in attention land" 描述内容带来的心理地位）。

一句话：**内容层解决"看不看"，心理层解决"回不回来"。**

## A1 — 书中的应用

来源是创作者本人经验，没有可引用案例。本批材料不含任何实验或前后对比数据。

合成演练（非语料案例）：一个讲 AI 工具的中文账号，原内容是"周更工具清单"（中立、无立场）。按本卡改：①选一个可讨论的立场（"大多数 AI 工具清单是在制造焦虑"）；②绑到已被讨论的对象（大厂发布会、知名工具）；③第一层只求"有点意思"，不求认同；④在文末给读者一个身份确认（"你是那种先看边界再看功能的人"）。该演练只演示操作，不产生效果证据。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `x-playbook`：那张卡是单条内容发布与承接（评论区/简介/置顶）；本卡是跨内容的受众关系建设。
- 与 `arousal-choice`：那张卡用有证据的唤醒度理论选情绪；本卡用未验证的心理操作建关系，证据等级低得多。
- 与 `content-business`：那张卡管"选谁、做多少条、怎么变现"；本卡管"怎么让人产生归属感"。
- 与 `promise-integrity`：本卡最容易滑向操纵；一旦涉及虚假身份、编造对立、制造焦虑，直接违反那张卡的红线。

## E — 执行 (Execution)

**输入**
- 账号定位与已有受众画像。
- 候选立场（2 个以上可讨论的观点；数量须自定）。
- 已有内容的互动数据（哪些话题引发了讨论）。

**步骤**
1. 选立场：写一句"这条内容站在哪一边"。完成标准：这句话能被反对，且反对者能说出理由。
2. 绑符号：从"大家已有看法"的品牌/人物/观念里选一个作为切口。完成标准：目标受众不需要背景解释就能参与讨论。
3. 定层级：这条内容瞄准第几层（轻度兴趣 / 主动搜索 / 主动等待）。完成标准：写清层级，且内容强度与层级匹配。
4. 给身份：设计一句让读者"被认出来"的表达。完成标准：这句话不是奉承，而是对读者行为的准确描述。
5. **伦理自查（强制）**：是否编造了对立、虚构了身份、利用脆弱人群？完成标准：四项全部为"否"，否则停止。

**分支**
- 新账号 → 只做第 1、2 步（立场 + 符号），不做身份层，避免用力过猛。
- 受众已稳定 → 可以减少立场强度，转向深度与一致性。
- 涉及争议人物/事件 → 停止使用本卡，改用事实梳理；避免煽动对立。
- 目标受众含未成年人或脆弱群体 → 禁用本卡。

**输出**
- 立场句 + 符号切口 + 目标层级 + 身份表达 + 伦理自查记录。

**完成标准**
- 四项操作均有明确产出；伦理自查四项全否；内容强度与层级匹配；没有编造对立或身份。

## B — 边界 (Boundary)

1. **证据等级：实践者（最低），且伦理风险最高。** 全部是经验主张，无实验、无数据；"cult audience""level one obsession"是营销概念，不是心理学结论。
2. **明确禁止的用法**：
   - 编造或放大群体对立来换取互动；
   - 虚构身份、经历、专业资质；
   - 针对未成年人、经济/健康脆弱人群做情绪操纵；
   - 用"归属感"包装付费陷阱。
3. **平台政策风险**：煽动对立、虚假身份在多数平台会被限流或封号；这条不是道德建议，是实际风险。
4. **与证据卡的边界**：`arousal-choice` 有综述证据、`story` 有元分析；本卡没有。任何引用都必须标明"实践者经验"。
5. **不承诺效果**：粉丝增长受选题、分发、时机影响极大；本卡只描述一种关系建设的操作，不保证涨粉或留存。
