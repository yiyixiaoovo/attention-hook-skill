# 黏性终检：六项一次过

## R — 原文 (Reading)

> Using the acronym SUCCESs, the authors described why some ideas are more memorable than others
> — made-to-stick-summary.txt, 正文（SUCCESs 段）

自译：作者用 SUCCESs 这个缩写，描述了为什么有些想法比另一些更容易被记住。

## I — 方法论骨架 (Interpretation)

发布前用一张六项清单逐条过。六项是**检查维度**，不是执行顺序：

- **Simple**：找到核心信息，并想清楚怎么传达它（不是「写短」）。
- **Unexpected**：用相关但未被预料的方式（见 `surprise-contrast`，不能用无关猎奇）。
- **Concrete**：让人能感同身受、容易理解（见 `concretize`）。
- **Credible**：让人信服，或容易自行检验——注意「可检验」只是可信的一种路径，不是必要条件（见证伪 p34）。
- **Emotional**：让人在意（二手定义，不等于 JMR 的高唤醒）。
- **Stories**：承载前几项，易记、能激励行动（结果变量是记住/行动，不等于转发）。

每项写下判定与一句依据；缺项就是改写点。拿到成稿后的顺序是：第一步写出一句话核心信息；第二步六项逐条判定并记下最弱项；第三步只改最弱项并复检——不要一次改六处，否则无法归因。然后按目标决定是否加一道 JMR 田野特征复核：实用、有趣、意外与「进入 most e-mailed 榜」正相关，但这是**控制变量、不是实验**，且「实用」在渠道上会反转，不能把三项当成普适打分表。

六项之间会冲突：为了 Simple 删掉限定条件，会伤 Credible 与准确；遇到冲突以准确与可信优先，再谈简化。六项也不可与 STEPPS 相加——两套清单有重叠，但语料对 STEPPS 只给了名称、没有定义与数据。

## A1 — 书中的应用 (Past Application)

语料无原书案例。CHOP 是二手书评、HBS 是访谈，本批材料没有原书、没有对照与测量；CHOP 评述者谈听众记忆时用的是猜测语气，不能当案例。本批材料没有作者亲历的叙事案例。

合成演练（非语料案例）：拿一条「如何减少无效会议」的成稿逐项打勾——Simple 有核心句；Concrete 有一个真实场景；Emotional 弱；Stories 缺；Credible 的演示不足。最弱项是 Stories，改写点是给一个真实人物的前后对比（事实须作者自核）。演练只演示检查动作，不产生任何效果证据。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `gap-design`（信息缺口）：本卡是成稿全面检查，缺口卡是开头结构；六项里的 Unexpected 属于 `surprise-contrast` 的地盘，不要与缺口检查混在一起。
- 与 `surprise-contrast`（预期违背）：造意外用那张卡，本卡只查「有没有」以及是否相关。
- 与 `concretize`（具体化）：改具体用那张卡，本卡只查 Concrete 项是否成立。
- 与 `arousal-choice`（情绪选型）：Emotional ≠ 高唤醒；不要拿 JMR 的情绪证据给六项打分或互证。
- 与 `distribution-first`（先看曝光）：先确认曝光正常，再花时间做终检；曝光不足时终检优先级最低。
- 与 `promise-integrity`（承诺兑现）：Credible 项与兑现相关，但六项通过不等于承诺兑现；最后必须单独跑兑现检查。

## E — 执行 (Execution)

**输入**
- 成稿或脚本；一句话核心信息。
- 目标结果变量：记住 / 转发 / 继续看——必须选一个，六项不能同时服务四个目标。

**步骤**
1. 六项逐条判定，并各写一句依据。完成标准：六项都有「达标/不达标 + 依据」，不是只写「通过」。
2. 标出最弱项或需优先改的项。完成标准：给出对应改写点，而不只是批评。
3. 冲突检查：列出为 Simple 删掉的限定条件，决定是否保留。完成标准：被删的限定有记录，准确与可信没有被牺牲。
4. 若目标为分享，加 JMR 三特征复核（实用/有趣/意外）。完成标准：三项各有判定，并标注证据只到邮件上榜、渠道敏感。
5. 若目标为记住，只用六项，不引用 JMR 传播结论。完成标准：结论写「更易记住」，不写「更易传播」。
6. 可选：请几位不了解你假设的人按维度独立评分（JMR 的测量方法，本语料只提供方法，不是效果证据）。完成标准：记录评分与分歧，不把自评分当行为证据。
7. 发布后：按配套的 `ab-log-guide.md`，用 `ab-log-template.csv` 记一次对照（一次只改一处、全程同一个指标、两组各 ≥10 条）。完成标准：基线、改动轴、两组指标与样本量都写进表里；样本不足就不下结论。

**分支**
- 若目标是「点开/完播」→ 停止：本卡（以及本批语料）不提供保证。
- 若目标是「转发」→ 可用六项，但必须加 JMR 三特征并注明渠道敏感。
- 若六项互相冲突 → 先保准确与可信，再谈简单与意外。
- 若某项无法判定（如 Credible 没有可检验凭据）→ 标「未达标」，不要默认通过。
- 若稿件还没有核心信息 → 先回 `gap-design` 或先写核心句，不要直接跑六项。

**输出**
- 六项检查表（判定 / 依据 / 改写点）+ 最弱项 + 冲突记录 + 目标结果变量声明。

**完成标准**
- 六项齐全且有依据；最弱项已改写或标为待改；目标变量已写明；没有把二手主张当实验，也没有把「记住」当「传播」。

## B — 边界 (Boundary)

**1）证据外推风险（必读）。** JMR 的因变量是「是否进入 2008 年《纽约时报》最常被邮件转发（most e-mailed）的列表」，不是点击率或完播率；其三个实验测的是自评分享意愿，不是真实分享。f10 的实用/有趣/意外只是田野控制变量，不是因果实验；「实用」在渠道上还会反转。因此六项+三特征不能被写成「提高点开/完播」的保证。

**2）二手摘要与引用边界。** f15 的 SUCCESs 六项来自 CHOP 书评与 HBS 访谈：是二手转述与作者主张，不是原书实验，无对照、无测量，结果变量是「记住」，不是分享。CHOP 评述者自己用猜测语气谈记忆；证伪 fx13 还指出该批材料在提取阶段被标为 medium，实际只能算作者主张——不得升格为「中等证据」或「研究表明」，也不得把二手转述标成原书实验。

**3）与「承诺兑现」的边界（防标题党）。** 六项过完不等于承诺能兑现：Credible 的「可检验」不是必要条件（p34 的 high 证伪：CHOP 原句是 convincing **or** easily tested，两条路径二选一；且可检验的假承诺仍然是假的）。本卡只管表达是否达标，不做真伪核查；发布前必须另跑 `promise-integrity`，核对标题/封面暗示的价值 ≤ 正文实际交付。六项之间会冲突，也不能把它当成无冲突的一次性套用清单。
