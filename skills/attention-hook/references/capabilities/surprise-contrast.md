# 预期违背：相关但没预料到

## R — 原文 (Reading)

> Unexpected refers to using relevant but unanticipated ways to both get and hold attention.
> — made-to-stick-summary.txt, 术语表 Unexpected

自译：意外（Unexpected），指的是用与主题相关、但读者没有预料到的方式，同时获取并保持注意。

## I — 方法论骨架 (Interpretation)

意外的可操作定义是「**相关但没预料到**」。要违背预期，读者必须先对这个主题有预期（常识、常见说法、直觉解释）；违背之后，角度还必须与主题相关——无关的猎奇画面只抓到注意，接不到内容上。

拿到一条内容后的操作顺序：

1. **列出预料**：写下读者对这个主题的常见说法、直觉解释、预期结果。
2. **选一个相关但未被预料的角度**：反常识的事实、被忽略的变量、看起来互相矛盾的两个现象。
3. **先呈现冲突，把解释留到后文**：让读者为了弄清楚「到底哪个变量在起作用」而继续看。语料里的实验室证据显示，儿童更愿意探索违背预期或因果被混淆的现象；这是儿童实验的转述，不是内容场景。
4. **区分获取与保持**：标题/封面/首句负责让人点开（获取层），开场后的信息推进负责让人看下去（保持层）。这是基于一句二手定义做出的设计分工假设，语料没有测过任一层，也没有任何时长数据。
5. **一致性检查**：意外点必须在正文得到解释，且解释与该意外相关；靠「震撼/颠覆」形容词堆出来的反差不算意外。

## A1 — 书中的应用 (Past Application)

语料无原书案例。CHOP 只给了一句二手定义；f04 来自 Kidd & Hayden 2015 综述转述的儿童玩具实验，是实验室任务，不是内容案例。本批材料没有作者亲历的叙事案例。

合成演练（非语料案例）：一篇讲「远程办公效率」的稿子，读者预料是「在家更高效或更低效」；选一个相关但未预料的角度——「真正的变量可能不是地点，而是省下来的通勤时间去了哪里」。开头先给一个与预期冲突的现象（同一批人换地点后效率方向并不一致），不解释；后文再把地点、通勤、时间分配几个变量拆开。演练只演示结构，不含语料案例，也不证明它更吸引人。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `gap-design`（信息缺口）：缺口是「我知道自己不知道 X」；预期违背是「我原以为 Y，结果不是」。前者可以没有对立面，后者必须先有预料；都可用于开头，但验收不同（问题有没有被回答 / 冲突有没有被解释）。
- 与 `arousal-choice`（情绪选型）：意外是内容特征（JMR 的编码项），高唤醒是情绪类别；同名不同测，不能用一个证明另一个。
- 与 `stickiness-pass`（黏性终检）：Unexpected 是六项之一，终检只查「有没有」；本卡负责怎么造，并额外检查相关性与后文解释。
- 与 `concretize`（具体化）：意外要靠具体事实承载；只有形容词的反差没有冲击。
- 与 `distribution-first`（先看曝光）：曝光不足时先查分发，不要靠加意外度掩盖分发问题。
- 与 `promise-integrity`（承诺兑现）：意外点必须后文解释；解释不了就是标题党，应删钩子或改钩子。

## E — 执行 (Execution)

**输入**
- 主题；目标读者对这个主题的预料清单（常见说法、直觉、预期结果）。
- 正文能解释的事实、变量、数据或案例。
- 标题/封面/首句草稿；若没有正文解释，先标「缺」。

**步骤**
1. 列预料：写出读者大概率会怎么想。完成标准：是具体说法，不是「他们没想过」。
2. 选相关但未预料的角度。完成标准：能用一句话说清「读者以为 X，实际可能是 Y」，且 Y 与主题相关、正文能解释。
3. 设计「先呈现、不解释」的开场。完成标准：冲突现象出现后，解释确实延后到后文；不是把无关猎奇前置。
4. 分层：获取层（标题/封面/首句）与保持层（开场后的推进）分别写内容。完成标准：两层各有设计，且标明这是推断性分工，不是已验证的两阶段模型。
5. 后文解释与拆变量。完成标准：正文有「到底哪个变量在起作用」的段落，能回答开场抛出的冲突。
6. 一致性检查。完成标准：钩子与正文主题一致；没有用形容词代替意外事实。

**分支**
- 若意外点与正文无关 → 删除，换相关角度。
- 若正文找不到解释 → 判停：这是标题党风险，删钩子或补内容。
- 若属安全提示、严肃通知、医疗告知 → 不制造意外。
- 若读者是专家或已确信 → 跳过基础，直接冲击其确定感，但仍需后文解释。
- 若只有形容词没有具体事实 → 退回 `concretize` 先把事实写具体。

**输出**
- 预料清单 + 钩子句 + 获取层/保持层设计 + 正文解释位置 + 一致性检查结论。

**完成标准**
- 钩子相关且被正文解释；没有无关猎奇；没有把「获取/保持」说成已验证模型；没有剂量参数承诺。

## B — 边界 (Boundary)

**1）证据外推风险（必读）。** JMR 的因变量是「是否进入 2008 年《纽约时报》最常被邮件转发（most e-mailed）的列表」，不是点击率或完播率；JMR 的 surprise 只是田野控制变量，没有独立实验。所以「意外提高上榜几率」不能写成「意外提高点开率/完播率」。f04 来自综述转述的儿童实验（探索行为与信息寻求），外推到成人信息流未验证。

**2）二手摘要与引用边界。** Unexpected 的定义来自 CHOP 二手书评，不是原书实验；「同时获取并保持注意」在语料里只有这一句，没有时长、没有测量，不得写成「已验证的两阶段模型」。JMR 的 surprise 与 CHOP 的 Unexpected 同名不同测，不能互证。凡引用二手摘要只能写「该书主张」。

**3）与「承诺兑现」的边界（防标题党）。** 意外点必须相关，并且在后文被解释；解释不了就删。语料没有研究标题党的代价，这是外部伦理约束。还要注意剂量冲突：JMR 田野里 surprise 与上榜是线性正相关，而 Kidd & Hayden 综述转述的婴儿注意证据是「中等信息量时最稳、两端都容易离开」——两条证据结果变量不同、方向不同，不能写成「越意外越好」，也没有可用的剂量参数（原文未给）；实操只能按目标与受众自测。
