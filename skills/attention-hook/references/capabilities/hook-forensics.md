# 爆款拆解：从一条已经爆的内容里提取可复用的结构

## R — 原文

> the easiest way to learn how to do this tactically is just study the videos on my channel I have 23 or 24 videos every single one of them follows this exact same framework
> — kallaway-transcripts-2026.txt（Kallaway, *How to write a killer script*；practitioner）

**这张卡不是证据卡。** 拆解是「从成功样本反推结构」，天然有幸存者偏差；拆出来的模板不保证下一条能复现。

## I — 方法论骨架

写之前先拆。四步：

1. **选样本**：同赛道、近期、高播放的 5–10 条；记录平台、时间、播放/互动（没数据就换样本，别凭感觉）。
2. **逐条拆**：每条填一张拆解表——
   - 标题：用了什么句式/数字/情绪词；
   - 封面/首帧：主文案、信息层级、有没有对比；
   - 开头 3 句：Lean（话题）/ Stop（转折）/ Snapback（反转）各自是什么；
   - 结构：分几段、每段功能、段间有没有 mini hook；
   - CTA 与结尾：求关注、给下一步、还是留问题。
3. **提炼结构**：把 5–10 条里重复出现的模式写成模板（槽位、顺序、字数区间），**只提炼结构，不抄句子**。
4. **改写并对照**：用自己的选题套模板写一版，再和样本逐项对照——哪一项刻意不同、为什么。

关键判据：**能说清「这条为什么用这个结构」，而不是「这条用了这个结构所以火」**。前者可复用，后者是倒果为因。

## A1 — 书中的应用

来源是创作者对自己频道的描述，没有可引用的案例数据。

合成演练（非语料案例）：拆 6 条「AI 工具测评」高播放视频。标题模式：3 条用「我测了 N 个」，2 条用「别再用 X」，1 条用数字对比；开头 3 句：4 条先给结论、2 条先给翻车；结构：5 条在第 2 段埋「但是最坑的是……」。提炼出「结论前置 + 第 2 段转折」的模板，再用自己的选题写一版并逐项对照。该演练只演示拆解流程，不产生效果证据。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `hook-craft`：那张卡是「写」；本卡是「写之前先拆」。拆完把模板交给 hook-craft 打磨句式。
- 与 `gap-design`：那张卡解释好奇心的机制；本卡只记录样本里「缺口出现在第几句」。
- 与 `packaging`：那张卡设计自己的标题/封面；本卡先统计样本的标题/封面模式。
- 与 `platform-native`：本卡拆内容结构；那张卡给平台参数。拆样本时两者一起用。
- 与 `video-metrics`：那张卡验证自己的效果；本卡只从公开数据选样本，不替代度量。
- 与 `surprise-contrast`：本卡统计「反差出现在哪」；那张卡讲反差的机制与剂量。

## E — 执行 (Execution)

**输入**
- 赛道关键词 + 平台。
- 5–10 条样本（链接/截图/数据）。
- 自己的选题与目标受众。

**步骤**
1. 建样本表：平台、发布时间、播放/互动、链接。完成标准：≥5 条，且有可比较的数据口径。
2. 逐条填拆解表（标题/封面/开头三句/结构/CTA）。完成标准：每条 5 项都有记录，不是「感觉不错」。
3. 标注重复模式：出现 ≥3 次的记成候选模板。完成标准：模板写成「槽位 + 顺序 + 字数区间」。
4. 用自己的选题套模板写一版。完成标准：每个槽位都有对应内容，没有空槽。
5. 逐项对照样本：哪些照做、哪些刻意不同、为什么。完成标准：差异有理由，不是随手改。
6. 发布后回填数据，更新模板库。完成标准：模板有「用了之后的数据」，不是只增不减。

**分支**
- 样本播放数据缺失 → 换有公开数据的平台/账号，不要用「我觉得火」当样本。
- 赛道样本太少 → 扩大到相邻赛道，但标注「跨赛道参考」。
- 拆完发现自己的选题套不进去 → 换选题，不要硬套模板。
- 样本里有擦边/违规内容 → 剔除，不进入模板库。

**输出**
- 样本表 + 每条拆解表 + 模板（槽位/顺序/字数）+ 改写稿 + 对照差异说明。

**完成标准**
- 样本 ≥5 条且有数据口径；每条 5 项齐全；模板可执行（有槽位和字数）；改写稿每槽有内容；差异有理由；有回填数据的机制。

## B — 边界 (Boundary)

1. **证据等级：实践者（最低），且方法本身有幸存者偏差。** 拆的是已经成功的样本，无法证明「照做就会成功」；样本选择、平台算法、时机都会影响结果。
2. **只提炼结构，不抄表达**：照搬句子/封面文案属于洗稿，违反平台规则与著作权；模板必须是抽象结构（槽位/顺序/字数）。
3. **平台差异**：同结构在小红书和 X 上效果不同；跨平台拆解要标注。
4. **样本污染**：买量、互推、擦边内容会污染样本；剔除或标注。
5. **不承诺效果**：本卡产出的是「可检验的假设」，验证回到 `video-metrics` 或自有 A/B 记录。
