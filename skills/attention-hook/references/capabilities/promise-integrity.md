# 承诺与兑现：别把钩子做成标题党

## R — 原文 (Reading)

> while negative emotions may hurt brand and product attitudes (Edell and Burke 1987)
> — berger-milkman-viral.txt, GENERAL DISCUSSION（负面情绪段）

自译：而负面情绪可能会损害品牌与产品态度（Edell 与 Burke，1987）。

## I — 方法论骨架 (Interpretation)

钩子本质上是向读者做的承诺：标题、封面、开头暗示「点开/看下去会得到 X」。这张卡把这个承诺变成可验收的对象。

1. **翻译成承诺句**：每个钩子（标题、封面、首句、开场问题）都写成一句「读者期待看到 X」。
2. **定位兑现位置**：在正文找到回答 X 的那一段/镜头。找不到就是未兑现：删钩子或补内容；不能只在标题里保留承诺、正文里不交付。
3. **核对承诺强度**：只能用内容实际交付的东西承诺，不能把没测过的结果变量写进标题。本语料的传播证据只到「被邮件转发/进入 most e-mailed 榜」与「自评分享意愿」，不覆盖点击率、完播率、涨粉；所以「看完就能 X」「完播率翻倍」这类承诺没有依据，属于过度承诺。
4. **可信路径是加分项，不是免责条款**：给数字、来源、可复现演示、可自行检验的路径；但一个可检验的假承诺仍然是假承诺（见证伪 p34）。

**代价面要单独算**：JMR 在讨论中引用文献承认负面情绪可能损害品牌与产品态度（该文自己并未测量品牌态度），说明「传播收益」与「信任代价」是两个结果变量；语料对「标题党被识破后的代价」零研究。因此「兑现」只能作为外部伦理约束 + 可操作性检查，不能伪装成语料结论。

最小规则：**标题/封面暗示的价值 ≤ 正文实际交付**。兑现不了就删钩子，不要删承诺。

## A1 — 书中的应用 (Past Application)

语料无原书案例。ce01 是 JMR 在讨论中引用他人研究并自认未测品牌态度；ce21 是方法部分对因变量的定义；两者都不是叙事案例，也没有「标题党—后果」的现场研究。

合成演练（非语料案例）：某条视频标题写「几个方法让你的完播率翻倍」，正文只给通用建议，既没有数据，也没有任何方法能让读者自行验证。本卡判定：第一，标题承诺的「完播率翻倍」超出本语料能支持的结果变量；第二，正文没有可定位的兑现段。动作是改标题为正文能交付的内容（删承诺，不是删钩子）。演练不冒充案例，也不提供真实数据。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `gap-design`（信息缺口）：缺口卡负责「造一个能兑现的问题」，本卡是终检，可否决任何钩子；缺口找不到兑现位置时，以本卡为准。
- 与 `surprise-contrast`（预期违背）：意外钩子最容易「抛完不管」；本卡检查意外点是否在后文得到解释。
- 与 `arousal-choice`（情绪选型）：愤怒/焦虑钩子最容易用恐惧做承诺；本卡检查威胁是否真实、是否由正文事实兑现。
- 与 `concretize`（具体化）：编造细节就是虚假承诺；具体化必须可回源，本卡验收的是「细节暗示的价值有没有交付」。
- 与 `stickiness-pass`（黏性终检）：Credible 项与兑现相关，但六项通过 ≠ 承诺兑现；「可检验」不是必要条件（p34 证伪），本卡必须独立跑。
- 与 `distribution-first`（先看曝光）：分发不足时不要用加码承诺补曝光——这正是标题党的动机来源；先查分发，再谈承诺。

## E — 执行 (Execution)

**输入**
- 标题、封面文字、开头原文；正文全文或脚本。
- 每条钩子暗示的承诺；可核验的证据/数据来源（若没有，标「无」）。
- 当前验收指标与用户能接受的信任成本（若用户未提供，先问再继续）。

**步骤**
1. 钩子 → 承诺句。完成标准：每个钩子都对应一句「读者期待看到 X」，没有遗漏封面与首句。
2. 在正文定位兑现段。完成标准：每条承诺都有段落/镜头编号；找不到的标「未兑现」。
3. 核对承诺强度与结果变量。完成标准：承诺的结果与内容实际交付一致；没有承诺点击/完播/涨粉等语料未覆盖的指标。
4. 补可信路径（可选）。完成标准：至少让读者能自行验证一条核心说法；做不到就改成观点。
5. 改写动作：删钩子 / 补正文 / 降承诺，三选一并说明理由。完成标准：每个未兑现项都有明确动作，且优先删钩子或补内容，不保留空承诺。

**分支**
- 若钩子无法兑现 → 先删钩子或补正文；用户拒绝补正文时，只输出删钩子建议（判停点）。
- 若用户要求「只要点击，不管兑现」→ 停止，并说明信任成本与后果。
- 若涉及医疗、金融、人身安全 → 不套用注意力技巧，建议专业处理。
- 若正文确实没有可兑现内容 → 直接说缺素材，不硬造钩子。
- 若承诺依据只是二手摘要或访谈 → 不得写进标题，只能当作者主张。
- 若承诺可检验但是假的 → 仍判不合格（可检验不等于真实）。

**输出**
- 钩子—承诺—兑现位置对照表 + 修改动作 + 未兑现清单 + 风险与缺失数据备注。

**完成标准**
- 每个钩子有兑现位置或已删；没有超出语料结果变量的承诺；用户已知缺失数据与信任代价；标题暗示价值不超过正文交付。

## B — 边界 (Boundary)

**1）证据外推风险（必读）。** JMR 的因变量是「是否进入 2008 年《纽约时报》最常被邮件转发（most e-mailed）的列表」，不是点击率或完播率；三个实验测的是自评分享意愿，不是真实行为。R 段「品牌与产品态度」一句是 JMR 引用 Edell and Burke 1987 的说法，JMR 自己**没有测量**品牌态度。所以：任何「用了这个钩子就能提高点击/完播」的承诺都缺证据；「传播有代价」也只能当风险提示，不能当已测结论。

**2）二手摘要与引用边界。** CHOP、HBS、Berger 访谈都只能提供「作者主张」，不得标成原书实验或「研究表明」。f15 的六项来自 CHOP 书评（无对照、无测量，结果变量是「记住」）；HBS 的 Jared 例子是作者直觉；访谈里的客户案例是自报、不可核验。把这些写进标题或承诺，等于用二手转述为效果背书。

**3）与「承诺兑现」的边界（本卡的硬规则）与三条 high 证伪结论。**

- **f20（证伪 high，fx02）**：逆向工程「天然黏性」内容只有成功样本，没有同题材总产量与失败样本对照，无法区分「特征导致流传」与「特征在同题材里本来就很常见」；作者自述方法无取样标准、无编码流程、无测量 → 幸存者偏差，不能据此反推因果，更不能用来承诺效果。f20 未通过验证。
- **p21（证伪 high，fx01）**：把「好奇最低」写成「读者不会想点开/会直接走开」是越界；原文因变量是自评好奇与为答案付费的意愿，没有点击或离开行为的测量。因此不能用点击语言做缺口承诺或验收。
- **p34（证伪 high，fx03）**：CHOP 原句是「convincing **or** easily tested」，可检验只是可信的两条路径之一，不是必要条件；也不能把「可检验」等同于「不虚假承诺」——一个可检验但虚假的承诺照样能通过。故本卡的硬检查是「标题/封面暗示的价值 ≤ 正文实际交付」，并声明它是外部伦理约束，不是语料发现。

此外，语料没有「标题党/欺骗被识破后的代价」的一手研究；本卡给的是可操作检查与伦理底线，不承诺「这样写就能既有点击又不损信任」。需要品牌/信任数据时，必须自己补测。
