# 故事的作用与滥用：更好懂好记，不等于更会说服

## R — 原文

> Based on over 75 unique samples and data from more than 33,000 participants, we found that stories were more easily understood and better recalled than essays.
> — narrative-memory-meta-2021.txt（Mar et al., 2021, *Psychonomic Bulletin & Review*）

同文报告平均效应超过半个标准差，且对单一研究不敏感；同时检出发表偏倚，并明确反对把一切信息故事化。

## I — 方法论骨架

故事不是「更高级的写法」，是一种**有适用边界的载体**。拿一条内容做决策，按三步走：

1. **先问目标**：这条要「让人记住/看懂」，还是「让人改变态度/转发」？
   - 记住/看懂 → 叙事有元分析支持（s01、s02）。
   - 态度改变/转发 → 证据不支持「故事更强」；不要用叙事承诺传播效果。
2. **目标匹配时才用叙事承载**：把核心信息放进一个有**具体人物 + 具体事件**的结构里，让读者跟着一个人经历一件事，而不是罗列概念。
3. **同时给故事设边界**：不把所有信息都故事化（s04）；引用效应量时说明它是**上限估计**（s03 发表偏倚）。

一句话：**故事负责「让人接得住」，不负责「让人被说服」。**

## A1 — 书中的应用

元分析本身没有叙事案例（它汇总的是实验）。本批材料不含「某账号改用故事后数据翻倍」这类案例，不得编造。

合成演练（非语料案例）：一段讲「量化对本地大模型的意义」的说明文，核心信息是「同样显存能跑更大模型」。叙事版：写一个人把 8GB 显存的旧笔记本从只能跑 7B，到跑通 14B 的过程，量化参数在情节里被自然带出。说明版：直接列三种量化方式的显存占用。两者对照时只问「读者能不能复述核心信息」，不问「哪个更打动人」——后者本语料没有证据。该演练只演示决策，不产生效果证据。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `concretize`（具体化）：具体化是**句子层**的改写（抽象名词→可感细节）；本卡是**体裁层**的决策（这段内容该不该用故事承载）。先决定体裁，再做具体化。
- 与 `gap-design`（信息缺口）：缺口管**开头怎么勾住**；故事管**正文怎么让人记住**。两者可叠加，但验收指标不同（继续看 vs 复述准确）。
- 与 `stickiness-pass`（六项终检）：那张卡里的「Stories」只是清单一项，来源是二手摘要；本卡是该项目的**一手证据与边界**。两者冲突时以本卡为准。
- 与 `promise-integrity`（承诺兑现）：本卡不判断故事真伪；但故事里的人物与事件若为虚构，必须标注，否则 Trigger「承诺兑现」的边界。

## E — 执行 (Execution)

**输入**
- 一段要传达的核心信息（一句话能说清）。
- 目标：记住 / 看懂 / 改变态度 / 转发——必须选一个。

**步骤**
1. 目标判定：写出目标变量。完成标准：明确写了「记住/看懂」还是「态度/转发」；没写的不许进入下一步。
2. 若目标是记住/看懂 → 设计「人物+事件」结构承载核心信息。完成标准：核心信息在情节里出现且不丢失；不是「讲个故事再硬拗道理」。
3. 若目标是态度改变/转发 → 停下，标注「本语料不支持用叙事承诺该效果」，改用其他卡（`arousal-choice`、`promise-integrity`）。完成标准：结论里没有「故事更有说服力/更容易传播」。
4. 边界检查：这条内容是否**本来就不适合叙事**（数据表格、合同条款、操作步骤）？不适合就不要强行故事化（s04）。完成标准：写了「适合/不适合」及理由。
5. 引用规范：若对外引用「故事提升记忆」，同时写「效应量平均 >0.5 SD，但该元分析检出发表偏倚，应视为上限」（s02+s03 必须成对）。完成标准：两个要素同时出现。

**分支**
- 内容以数据/流程为主 → 用「数据 + 一句人话解释」，不要编故事。
- 读者是专业同行、已具备背景 → 故事的增益下降，优先效率（该边界为推断，语料未直接测）。
- 故事人物是虚构 → 必须标注「情节为示意」，不冒充真实案例。
- 目标是转发 → 转 `arousal-choice`，不要用故事说服。

**输出**
- 体裁决策（叙事 / 非叙事 / 混合）+ 核心信息落点 + 边界检查结论。

**完成标准**
- 目标变量明确；没有把「记住」偷换成「说服」；引用效应量时带发表偏倚提示；虚构情节已标注；不适合叙事的内容没有被强行故事化。

## B — 边界 (Boundary)

1. **结果变量是理解与回忆**：元分析测的是「故事比说明文更好懂、更好记」，不是态度改变、购买、转发或完播。把这些写成故事的效果属于越界。
2. **效应量可能被高估**：该元分析自己检出发表偏倚，低精度研究报告的效应更大（s03）；引用时应说明 0.5 SD 是上限估计。
3. **作者反对全盘故事化**：原文明确说该结果不应被理解为「建议把所有信息强行写成故事」（s04）。故事是体裁选择，不是通用模板。
4. **样本与场景偏**：纳入研究多来自教育/健康传播，多为即时纸面测试；混合体裁（如叙事新闻）、延时回忆、听觉/视频呈现的证据很少。
5. **叙事 vs 非叙事的说服正面对比尚无定论**：本批材料没有纳入该问题的开放获取证据，不得宣称「故事更能说服」。
6. **分享/转发没有证据**：语料中没有任何研究同时做叙事/非叙事对比与自主选择观看设计，所以「故事更易被转发」无依据。
