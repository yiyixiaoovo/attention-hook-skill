# 信息缺口设计：先给一点，再留一个能兑现的问题

## R — 原文 (Reading)

> a small amount of information serves as a priming dose, which greatly increases curiosity.
> — kidd-hayden-2015-curiosity.txt, THE FUNCTION OF CURIOSITY

自译：少量信息起到「引子剂量（priming dose）」的作用，会大大提升好奇心。

## I — 方法论骨架 (Interpretation)

好奇心由**读者自己感知到的信息缺口**驱动，不是由信息量或神秘感驱动。拿到一篇文章或一条视频后，按三步搭开头：

1. **先给引子剂量**：开头先放一小段读者已能理解的具体信息（一个事实、一个场景、一个数字），让他站到「知道一点」的位置。空开场直接提问不算缺口，那是没有信息。
2. **只开一个缺口**：用一句话让读者自己意识到「我还不清楚 X」，而且是正文会回答的 X。缺口要落在读者已有一点概念的地方，不是挖一个他完全不关心的洞；不要替读者下判断，也不要一次抛出多个悬念。
3. **把核心信息排在好奇之后**：先制造一个可解的好奇点，再把最想让人记住的那一条放在回答它的段落或镜头里；综述转述的实验显示，高好奇状态下连无关材料也记得更好，但结果变量是学习与记忆，不是点击。

**校准缺口大小**：完全陌生（没线索）与已经确信（没缺口）两端好奇都低，目标是「有点概念但没把握」的中间态。缺口是相对受众已有知识定义的，不是绝对信息量；语料没有给出可换算的数值参数。

**长内容分段**：一个缺口被回答后（信息被消费会产生饱足），再开下一个；一条内容只保留一个主缺口。

**最后一道是兑现**：缺口必须在正文里有明确回答位置。语料没有研究「不兑现的代价」，所以这条是外部伦理约束与自测项，不是语料发现。

## A1 — 书中的应用 (Past Application)

语料无原书案例。Kidd & Hayden 2015 是同行评议综述，转述的是 trivia、模糊图片、婴儿序列等实验室任务，不是内容生产的叙事案例；本批材料没有作者亲历或可复算的稿件案例。

合成演练（非语料案例）：一篇讲「会议为什么总开不完」的稿子——开头先给读者熟悉的场景（周一早会一路拖到午饭），这是引子；随即只留一个问题：「多出来的时间到底花在哪个环节？」；正文第二节回答它，回答之后再开下一个缺口。此演练只演示步骤，不产生任何效果证据；实际是否让人看下去，须自己小样本测试。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `arousal-choice`（情绪选型）：本卡服务「想不想知道、要不要看下去」（信息寻求侧）；情绪卡服务「愿不愿意转发/行动」（分享侧）。语料没有把两条链连起来的证据，不能用一个证明另一个。
- 与 `surprise-contrast`（预期违背）：缺口是「我知道自己不知道 X」；预期违背是「我原以为 Y，结果不是」。前者靠问题，后者靠冲突现象；同一条开头可以叠用，但要分别验收（问题有没有被回答 / 冲突有没有被解释）。
- 与 `concretize`（具体化）：缺口的引子必须是具体可感的事实；具体化卡负责把抽象句换成可感知细节，本卡只决定信息顺序。
- 与 `stickiness-pass`（黏性终检）：六项里的 Unexpected 与本卡都在开头争夺注意，但机制不同（预期违背 vs 知识缺口）；六项是成稿检查表，本卡是开头结构设计，两者不能当两条独立证据相加。
- 与 `distribution-first`（先看曝光）：曝光不足时先查分发，不要用「缺口不够」解释没人看。
- 与 `promise-integrity`（承诺兑现）：本卡负责造缺口，兑现卡负责验收「承诺 ≤ 交付」；缺口找不到兑现位置时，以兑现卡为准，删缺口。

## E — 执行 (Execution)

**输入**
- 目标读者现在已知什么（一句话）；未知则先问用户或做小样本，不能静默假设。
- 本文/本条视频真正能回答的问题，以及核心信息一条。
- 内容形态与兑现位置（正文第几段 / 第几秒回答它；没有就标「无」）。

**步骤**
1. 写「读者已知」一句，再写引子：一个具体事实、场景或数字。完成标准：引子可被目标读者认作自己的处境，且引子本身不是结论。
2. 只开一个缺口，写成读者会自己问的问题。完成标准：句中含「我还不知道 X」，X 是正文会回答的东西；不是「你一定想不到」式空悬念。
3. 把核心信息移到回答缺口的段落/镜头。完成标准：核心信息不在开头一次说完；回答缺口处就是核心信息出现处。
4. 长内容分段开缺口：答完一个再开下一个，保持一个主缺口。完成标准：每个缺口都有回答；同一段没有并列多个悬念。
5. 兑现检查：把每个缺口与正文回答位置一一对应。完成标准：每个缺口都有可指出的回答段；没有的删缺口或补内容（判停点：补不了就删）。
6. 受众校准：写下受众知识层级（陌生/半熟/专家）与依据。完成标准：缺口大小与该层级匹配；无法估计时标「未校准」，不要假装校准过。

**分支**
- 若读者完全陌生 → 先补最低必要背景再开缺口（缺口太大时好奇反而最低）。
- 若读者是专家或已确信 → 跳过基础，直接给未解细节或冲击其确定感。
- 若长内容 → 分段开缺口，一段一个。
- 若缺口在正文找不到兑现位置 → 停止：删缺口或补内容，不得保留空钩子。
- 若素材本身没有缺口（纯通知/公告）→ 停止，不硬造钩子。

**输出**
- 引子段 + 缺口句 + 核心信息位置 + 缺口—兑现位置对照表 + 受众校准说明（或「未校准」标记）。

**完成标准**
- 四件套齐全；缺口是读者会自己问的；每个缺口都有兑现位置；未把点击/完播当验收；未校准处已如实标注。剂量参数原文未给，执行时自定并注明是约定。

## B — 边界 (Boundary)

**1）证据外推风险（必读）。** JMR（Berger & Milkman 2012）的因变量是「是否进入 2008 年《纽约时报》最常被邮件转发（most e-mailed）的列表」，不是点击率、完播率或播放量；本卡核心依据 Kidd & Hayden 2015 的结果变量是信息寻求、注意与学习，也不是点击或观看时长。因此，「这样设计能提高打开率/完播率」在本语料中没有一手证据；缺口设计只能作为方向性假设，上线前必须用小样本自测继续看的意愿与缺口兑现度。

**2）二手摘要与综述的引用边界。** 本卡不引用 CHOP/HBS/访谈。Kidd & Hayden 是同行评议综述（Perspective、选择性综述），只能写「综述汇总显示」，不能写「实验证明」——其转述的原始实验不在语料内。别处若出现 CHOP/HBS 的说法，只能写「该书主张/作者主张」，不得包装成原书实验。

**3）与「承诺兑现」的边界（防标题党）。** 缺口必须真实：正文要回答被钩住的那个问题。语料没有研究「不兑现/标题党」的代价，所以「缺口必须兑现」是外部伦理约束，不是语料发现；做不到兑现时删钩子，不要改用「你一定想不到」式空悬念或夸大承诺。另：Goldilocks 的「适中」没有数值参数（原文未给），不能写成「悬念留几秒 / 给几个信息点」的配方；「好奇最低」也不能写成「读者会直接走开/不会点开」——证伪 fx01 的结论是：原文因变量只是自评好奇与付费意愿，没有点击或离开行为测量。

**4）自有小实验的结论（2026-11-23，`experiments/hook-ab/`）。** 用 4 种开头类型 × 3 个主题 × 5 名盲评者做过一次对照：信息缺口型的「继续看」中位数确实最高（6 vs 结论前置 5），但按预注册规则（差 ≥1.0 且 ≥2/3 主题严格领先）**只有 1/3 主题成立，判定为「无足够信号」，不能据此宣称信息缺口更好**；按均值看两者只差 0.27 分。可记的观察只有两条：**直接提问型明显最弱**（与「空提问不构成缺口」方向一致），**具体细节型不适合当标题**（点开意愿偏低）。该实验的评者是 LLM 不是真人，只能算方法验证，不能当效果证据。
