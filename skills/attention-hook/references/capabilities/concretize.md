# 具体化改写：抽象名词换成可感知的细节

## R — 原文 (Reading)

> Concrete refers to presenting ideas in ways that are relatable and easy to understand.
> — made-to-stick-summary.txt, 术语表 Concrete

自译：具体（Concrete），指的是用能让人产生共鸣、容易理解的方式来呈现想法。

## I — 方法论骨架 (Interpretation)

具体化的操作定义是：让读者能在脑子里「看见」这句话，而不只是认识这些词。拿到一份稿子后，逐句扫描三类东西——抽象名词（体验、效率、价值）、行业术语与缩写、概括性动词（优化、赋能、提升）——每一处追问四件事：**具体是谁？在什么场景？做了什么动作？结果是什么？** 然后用回答替换原句。

细节必须真实可核：细节是可信的载体，编造细节会把「具体」变成虚假承诺。有具体来源的，标出来；没有来源的，改成观点或删掉，不要为了画面感补造数字与情节。

同时做**知识诅咒自检**：假设读者完全在你的领域之外，凡是你心里想「这他当然知道」的地方，都是需要补例子或删术语的地方。专家越懂，越容易省略掉新手唯一需要的那一步；「写具体」往往不是加细节，而是把被省略的动作补回来。

注意剂量：具体不等于细节越多越好。细节过密会伤简单与节奏，语料没有「越具体越好」的剂量证据；目标是可感知、可想象，不是堆信息。

## A1 — 书中的应用 (Past Application)

语料无原书案例。CHOP 是《Made to Stick》的书评二手摘要，HBS 是作者访谈，两者合计转述了少量书中例子（如 Jared、cantaloupe），但本语料没有原书，也没有可复算的案例；这些例子不能当案例研究或效果证据。

合成演练（非语料案例）：原句「我们提升了售后体验」→ 追问是谁、在什么场景、做了什么、结果是什么 → 改成「用户报修后，第一个接电话的人就能查到他的订单，不用再转一次」。演练只演示改写路径，具体事实必须由作者自己核实；演练不提供任何真实数据，也不证明改完更有效。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `gap-design`（信息缺口）：缺口卡决定开头的信息顺序，本卡负责全篇表达；缺口的引子要用具体事实，但具体化手术由本卡做。
- 与 `stickiness-pass`（黏性终检）：Concrete 只是六项之一；终检判断「有没有」，本卡做逐句改写，六项齐过不能替代逐句扫描。
- 与 `surprise-contrast`（预期违背）：意外要靠具体事实承载，抽象的反差没有冲击；但本卡不改结构。
- 与 `arousal-choice`（情绪选型）：具体细节是情绪的载体；本卡不改情绪基调。
- 与 `promise-integrity`（承诺兑现）：编造细节就是虚假承诺的一种；本卡的真实性核对与兑现卡的承诺检查互补。
- 与 `distribution-first`（先看曝光）：受众知识水平与渠道决定抽象容忍度；先确认受众与渠道，再决定改写到多具体。

## E — 执行 (Execution)

**输入**
- 稿件全文；目标读者领域（外行 / 半熟 / 内行）；发布渠道。
- 可用的真实素材：人物、动作、数字、场景、截图、可回源的出处。
- 若真实素材不足，先说明「只能改表达、不能补事实」，不许静默编造。

**步骤**
1. 标出所有抽象名词、缩写、术语、概括性动词。完成标准：清单逐条对应原文句子，没有漏标整段。
2. 每一处回答「谁 / 在哪 / 做了什么 / 结果是什么」，写出改写句。完成标准：每处都有具体主语与动作；不新增无法核实的数字。
3. 知识诅咒自检：逐条问「读者要先知道什么才懂」，补一个具体例子或删掉术语。完成标准：每个术语首次出现有例子，或被删。
4. 真实性与密度核对：删掉不服务理解的细节，核对每个细节能否回源。完成标准：细节可回源；没有为具体而编造；没有因堆细节拖垮节奏。
5. 保留限定条件：改写时不能删掉影响准确性的前提。完成标准：原文的限定与例外仍在。

**分支**
- 若受众是同行专家 → 保留术语，只补关键动作与判断依据。
- 若素材里没有可核实细节 → 不编，改成观点或删句。
- 若属学术、法律、合同等必须抽象严谨的文本 → 不套本卡。
- 若涉及高风险专业内容 → 不擅自简化关键限定，必要时建议专业复核。
- 若一个抽象句改不动（缺事实）→ 判停：标记「待补素材」，不要用形容词硬撑。

**输出**
- 逐句对照表：原句 / 追问得到的答案 / 改写句 / 真实性来源 / 保留的限定条件。

**完成标准**
- 抽象句清零或已注明保留理由；每处细节可回源；没有新增事实；知识诅咒点已处理。

## B — 边界 (Boundary)

**1）证据外推风险（必读）。** JMR 的因变量是「是否进入 2008 年《纽约时报》最常被邮件转发（most e-mailed）的列表」，不是点击率或完播率；JMR 没有测过具体化，别用它的传播结论为「具体化提高点击/转发」背书。本卡的证据本身也只到「理解/记住」这一侧，且是作者主张，不到行为指标。

**2）二手摘要与引用边界。** 本卡依据的 CHOP 书评与 HBS 访谈都是二手材料：CHOP 是对原书的转述，HBS 是作者访谈；它们不是原书实验，没有对照与测量。只能写「该书主张」「作者主张」，不得写成「研究表明」或「原书实验证明」。知识诅咒只有类比，没有测量；「六项原则是解药」也是作者主张，不是验证结果。

**3）与「承诺兑现」的边界（防标题党）。** 具体细节必须真实可核：编造细节=用具体化包装虚假承诺，读者一旦发现，损伤的是整条内容的可信度。语料没有「细节越多越好」的剂量证据，也没有「具体化能提高点击/完播」的数据；「具体」不能用来制造无法交付的画面。标题与开头给出的具体承诺，正文必须能兑现。
