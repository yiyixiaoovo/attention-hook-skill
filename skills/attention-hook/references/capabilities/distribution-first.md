# 先看曝光位置，再改文案

## R — 原文 (Reading)

> While being featured prominently, for example, increases the likelihood that content will be highly shared
> — berger-milkman-viral.txt, GENERAL DISCUSSION

自译：例如，被显著地放在突出位置，会提高内容被大量分享的可能性。

## I — 方法论骨架 (Interpretation)

内容表现不好时，第一步不是改标题，而是把问题归因分清楚。按顺序做三步：

1. **记录首轮曝光条件**：发布位置/推荐来源、曝光量、发布时段、渠道，以及同位置同时段的基线内容。
2. **把「没被看到」和「看到了不想点/不想看」分开**：与同位置、同时段的基线比较，而不是与爆款比较。曝光异常 → 先改分发；曝光正常 → 才改内容特征。JMR 的结论是曝光位置与内容特征「同量级」，不是「内容为王」，也不是「位置决定一切」。
3. **再看渠道方向**：同一内容特征在不同渠道可能方向不同。JMR 田野里「实用价值」在邮件/订阅型渠道是加分项，在博客型渠道的补充样本中是边际负向（作者只推测原因：博客本身是评论性内容）；同一篇稿子应为两类渠道准备不同包装：订阅型强化可执行清单，公开评论型强化观点与评论角度。

关键限制：JMR 的「位置」是 2008 年《纽约时报》首页的不同区域与停留时长，由编辑流程独立决定；它不是 2020s 的算法推荐或流量池，也不是作者可以随手拨动的杠杆。迁移时只能记录可观测的推荐来源占比，不能假装能把曝光与内容表现干净分层。

## A1 — 书中的应用 (Past Application)

语料无原书案例。JMR 是田野数据的统计研究，不是叙事案例；博客渠道的反转来自补充抓取的小样本。本批材料没有作者亲历的内容案例。

合成演练（非语料案例）：一条视频播放量低——先列推荐来源占比、发布时段、同位置同时长视频的基线；若曝光正常，再改封面/前几秒；若曝光异常，先处理发布渠道与时段，暂时不动文案。演练不提供任何真实平台数据，也不证明该做法一定有效。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `gap-design`（信息缺口）、`surprise-contrast`（预期违背）、`concretize`（具体化）：这几张都改「被看到之后」的内容；本卡是前置归因，曝光不足时先不要动它们。
- 与 `arousal-choice`（情绪选型）：情绪与文案只影响「被看到后」的传播意愿，救不了没有曝光的内容。
- 与 `stickiness-pass`（黏性终检）：终检之前先确认这条内容值得改；分发正常才进入终检。
- 与 `promise-integrity`（承诺兑现）：分发差的时候最容易用更夸张的标题/封面补曝光，本卡要求不要这样做；兑现卡负责检查承诺是否超出交付。

## E — 执行 (Execution)

**输入**
- 曝光位置/推荐来源、曝光量、首轮流量占比、发布时段、渠道。
- 同位置同时段的基线数据（没有就标「缺」）。
- 内容侧数据（点击/转发/观看等已有的部分）与当前验收目标。

**步骤**
1. 记录曝光条件。完成标准：能回答「这条被谁看到、在哪里被看到、曝光量是多少」。
2. 与同位置同时段基线比较，不与爆款比较。完成标准：对照数据存在，比较对象同类。
3. 归因：曝光异常 → 分发问题；曝光正常且点击/传播低 → 内容问题。完成标准：写下一条归因结论并附数据。
4. 渠道匹配：判断主要渠道类型（订阅/邮件/私聊 vs 公开博客/评论），决定包装方向。完成标准：该方向有基线，或明确标「待自测」。
5. 给出下一步：先改分发还是先改内容。完成标准：动作与归因一致，不同时改两头。

**分支**
- 若没有曝光数据 → 先补数据，不臆断「文案不行」（判停点：数据补齐前不改文案）。
- 若曝光正常 → 才进入内容类能力卡。
- 若渠道不明 → 先问用户渠道，不能直接套用邮件时代结论。
- 若属算法信息流 → 明确说曝光与内容表现可能互为因果、无法干净分层，只能记录推荐占比并做同期对照。
- 若用户同时要改分发和内容 → 先固定分发变量，再测内容，否则无法归因。

**输出**
- 归因结论（分发问题 / 内容问题）+ 依据数据 + 下一步动作 + 渠道包装建议 + 缺失数据清单。

**完成标准**
- 结论有对照数据；没有把分发问题当文案问题；没有把 2008 年邮件结论直接套到公开或算法渠道；缺失数据已如实标注。

## B — 边界 (Boundary)

**1）证据外推风险（必读）。** JMR 的因变量是「是否进入 2008 年《纽约时报》最常被邮件转发（most e-mailed）的列表」，不是点击率或完播率；「位置」是 2008 年 NYT 首页区域与停留时长，不等于算法推荐/流量池。原文只说位置与内容特征「同量级」，没有可移植的百分比；曝光与内容表现可能互为因果，不能干净分层（证伪 fx07）。博客渠道的反转只是边际效应 + 作者推测，25 篇样本之外的渠道没有数据，尤其没有 2020s 的中文平台数据。

**2）二手摘要与引用边界。** 本卡只用 JMR。别处若用 CHOP/HBS/访谈的「实用就火」「六原则」来支持分发策略，只能写「该书主张/作者主张」，不得标成原书实验；它们与 JMR 的田野证据不是同一结果变量。

**3）与「承诺兑现」的边界（防标题党）。** 分发不足时，不要用更夸张的标题/封面去补曝光——这正是标题党最常见的动机。本卡建议先修分发或渠道；语料没有研究「标题党被识破后的代价」，所以「不用夸大承诺补曝光」是外部伦理约束，不是语料发现。若必须改标题，先过 `promise-integrity` 的兑现检查。
