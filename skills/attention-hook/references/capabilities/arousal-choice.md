# 情绪选型：看唤醒度，不看正负

## R — 原文 (Reading)

> Content that evokes high-arousal positive (awe) or negative (anger or anxiety) emotions is more viral.
> — berger-milkman-viral.txt, Abstract

自译：唤起高唤醒正面情绪（敬畏）或高唤醒负面情绪（愤怒、焦虑）的内容，更容易被传播。

## I — 方法论骨架 (Interpretation)

先分清情绪的两个维度：**效价**（正面/负面）与**唤醒度**（是否让人想行动）。JMR 的田野结果是：正面内容比负面内容更易传播，但效价解释不了全部；高唤醒的正面（敬畏）与负面（愤怒、焦虑）情绪提升传播，低唤醒的去激活情绪（如悲伤）降低传播；厌恶在该语料中没有显著关系。可迁移的操作分三步：

1. **逐段标主情绪**：给每一段/每个镜头写一个主情绪名称，并判它是高唤醒还是低唤醒。
2. **低唤醒换框架**：若主调是悲伤、放松、满足，就用同一事实换一个高唤醒入口——敬畏（规模、大图景、震撼但真实）、愤怒（不公）、焦虑（紧迫、风险）、幽默（荒诞对照）。**事实与数字不许改**，只换框架。
3. **先正面、再负面**：能正面说就正面说；必须负面时，先确认它是高唤醒，再评估品牌/信任代价。不把「负面」当整体按钮：厌恶类素材目前没有正证据，悲伤作主调会压低传播。

验收目标只能写「分享/转发」这一侧：本语料没有测过点击、观看、完播，不能写成「用了就会火」。

## A1 — 书中的应用 (Past Application)

语料无原书案例。JMR 只有三个实验的刺激材料（广告故事、客服故事、新闻故事），是实验室材料，不是叙事案例；而且结果变量是自评分享意愿。本批材料没有作者亲历的内容案例。

合成演练（非语料案例）：一条讲「城市通勤变长」的数据稿，原稿主调是「无奈/怀念」（低唤醒悲伤）。保留原稿的真实数字，把入口换成敬畏（把真实的年度通勤总时长换算成「相当于多少天」的大图景）或焦虑（赶不上家里晚饭的紧迫），正文再给可行动的那一部分。演练只演示换框架，不新增任何数字，也不构成效果证据；是否提升分享须自测。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `gap-design`（信息缺口）：本卡属「传播链」，缺口卡属「信息寻求链」；语料没有交叉证据，不可互证——好奇心不证明转发，高唤醒不证明看完。
- 与 `surprise-contrast`（预期违背）：JMR 的 surprise 是内容特征控制变量，唤醒是情绪类别；意外不等于高唤醒，不能拿意外度当情绪强度。
- 与 `concretize`（具体化）：情绪要落在具体事实与画面上；本卡选情绪方向，具体化卡负责载体。
- 与 `stickiness-pass`（黏性终检）：SUCCESs 的 Emotional 是「让人在意」（二手主张），不是 JMR 的高唤醒；同名不同测，不能相加或互为证据。
- 与 `distribution-first`（先看曝光）：渠道或曝光异常时先查分发；同一情绪方案在不同渠道的可迁移性，语料未测。
- 与 `promise-integrity`（承诺兑现）：愤怒/焦虑最容易滑向恐惧营销；本卡给「可用条件（高唤醒 + 代价可承受）」，兑现卡验收威胁与承诺是否由正文事实兑现。

## E — 执行 (Execution)

**输入**
- 稿件或脚本分段、每段想引发的情绪；发布渠道；当前验收指标。
- 若用户只给点击/完播目标，先说明本卡证据不支持该结果变量，再决定是否继续。

**步骤**
1. 逐段标注主情绪、效价、唤醒高低（按语料四类高唤醒：敬畏、愤怒、焦虑、愉悦；悲伤属低唤醒）。完成标准：每段都有标注，并明确指出低唤醒段。
2. 判正负：能正面框架就正面；必须负面时，检查是否为高唤醒，且不用厌恶或悲伤作主调。完成标准：负面段有一个可行动的出口。
3. 改写低唤醒主调：用同一事实换高唤醒入口，标题/开场优先承载。完成标准：事实与数字零改动；改写版仍与正文一致。
4. 风险检查：负面方案写明品牌/信任代价与高风险话题限制。完成标准：涉及健康、灾难、未成年人、公共政策时，不使用愤怒/焦虑。
5. 验收设定：把指标写成分享/转发，或注明「本卡无法承诺点击/完播」。完成标准：验收口径和证据结果变量对齐。

**分支**
- 若内容目标是安抚、哀悼、陪伴 → 不套本卡（低唤醒是目的，不是缺陷）。
- 若属高风险话题 → 不用愤怒/焦虑，改敬畏或幽默；这是伦理红线。
- 若只有点击/完播指标 → 停止，说明证据不支持，再决定是否改用别的目标。
- 若负面题材找不到可行动部分 → 保留事实但不上愤怒/焦虑框架，或改成观点。
- 若渠道是公开信息流 → 标注「邮件时代的结论须重测」，不直接套用。

**输出**
- 逐段情绪标注表（段落 / 主情绪 / 效价 / 唤醒 / 依据）+ 标题与开场候选 + 品牌风险备注 + 验收口径说明。

**完成标准**
- 主情绪不是低唤醒；事实与数字零新增；负面方案有代价评估；验收指标不与语料的结果变量错位。

## B — 边界 (Boundary)

**1）证据外推风险（必读）。** JMR 的因变量是「是否进入 2008 年《纽约时报》最常被邮件转发（most e-mailed）的列表」，不是点击率、完播率或转化；三个实验（自评分享意愿、单个故事刺激、无信息流环境）也不是真实分享行为。把「高唤醒提升传播」写成「提高点开/完播」即越界；2008 年美国精英媒体的邮件语境外推到 2020s 算法信息流，必须重测。

**2）二手摘要与引用边界。** 本卡只用 JMR；不得把 CHOP/HBS/访谈的「Emotional（让人在意）」当成 JMR 的唤醒度，那是同名不同测、不可互证。也不得把二手摘要的清单写成「原书实验」。JMR 的「唤醒」在田野部分是按情绪类别做的先验假设，不是生理测量；情绪编码的输入是标题与摘要——这些都要随结论一起说明。

**3）与「承诺兑现」的边界（防标题党）。** 负面高唤醒不得变成恐惧营销或虚假威胁：标题里的愤怒/焦虑必须由正文的**真实事实**兑现。JMR 自己引用文献承认负面情绪可能损害品牌与产品态度，但该文并未测量品牌态度；语料对「标题党/欺骗被识破后的代价」零研究。所以用负面情绪换传播时，要单独评估信任成本，不能宣称两全；公共健康与高风险话题优先用可信、可检验的信息，不用恐惧替代信息。
