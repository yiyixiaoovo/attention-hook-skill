# 脚本流程：包装 → 大纲 → 开场 → 正文 → 结尾

## R — 原文

> okay so these are the five script writing steps in the process number one is packaging number two is outline number three is intro number four is body and number five is outro I write every single script in this exact same order
> — kallaway-transcripts-2026.txt（practitioner）

**这张卡不是证据卡。** 这是一套创作者的写作流程，没有对照实验；「更好」的判断只能靠自己的数据。

## I — 方法论骨架

一条视频的脚本按固定五步走，**顺序本身就是方法**：

1. **Packaging（包装）**：先定标题与封面，再动笔。包装决定了这条视频要写什么。
2. **Outline（大纲）**：列出要讲的点，并排优先级——不要按想到的顺序写。
3. **Intro（开场）**：确认点击 + 引出第一个点。
4. **Body（正文）**：逐点展开；点与点之间用 **mini hook（再钩）** 衔接，让人必须听到下一个点（原文举例："这个点很重要，但如果不配上下一个，魔法就没了"）。
5. **Outro（结尾）**：回收痛点、总结，并留一个**高音符**（原文比喻：餐厅结账时送的那块免费巧克力）——这是提升点赞、转发、重看的最后一步。

节奏上还有一条：**大图—战术交替**（原文："constant zoom in and zoom out… big picture going down for the tactics"），先给全局再给操作，再回到全局。

## A1 — 书中的应用

来源是创作者对自己频道的描述，没有可引用的案例。本批材料不含"按这个流程写播放涨了 X%"的数据。

合成演练（非语料案例）：一条 3 分钟的「AI 工作流」视频。包装定为「我把周报从 2 小时压到 10 分钟」；大纲列三点（痛点、方法、边界）；开场 5 秒展示计时器与结果；正文每点结尾埋一句「但真正的坑在下一步」；结尾回收「2 小时→10 分钟」并给一个可立刻执行的小动作。该演练只演示流程，不产生效果证据。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `packaging`：那张卡产出标题/封面/开场承诺，是**本卡第一步的输入**。
- 与 `hook-craft`：那张卡打磨开场几句话（六槽/三拍/四错）；本卡管**整篇结构**与段落衔接。
- 与 `story-craft`：故事是内容形态选择；本卡是脚本骨架，两者可叠加（故事型视频也用五步）。
- 与 `stickiness-pass`：那张卡是发布前表达自检；本卡是写作时的流程。
- 与 `x-playbook`：本卡产出脚本，那张卡管发布与承接。

## E — 执行 (Execution)

**输入**
- 选题、目标人群、一条视频的核心结论。
- 已有的标题/封面（没有就先做 `packaging`）。

**步骤**
1. 包装：确认标题与封面。完成标准：标题承诺在脚本里有落点。
2. 大纲：列出 3–5 个点，标出「第一个点」与「最强点」。完成标准：顺序不是"想到的顺序"，而是按注意力设计的顺序。
3. 开场：3–5 秒确认点击 + 抛出第一个点。完成标准：不跑题、不提前泄底。
4. 正文：逐点展开；每点结尾写一句衔接（mini hook）。完成标准：相邻两点之间有过渡句，删掉过渡句会让人感觉"跳了"。
5. 节奏检查：至少有一次"全局→战术→全局"的往返。完成标准：能指出具体在哪个位置做的往返。
6. 结尾：回收开头痛点 + 总结 + 高音符。完成标准：结尾有一句能被记住的话，且不是"求关注"。
7. 通读：删掉所有不承担"推进或证明"功能的句子。完成标准：每一句都能说出它的作用。

**分支**
- 短视频（<60 秒）→ 五步压缩为三步：包装、开场+正文合一、结尾一句；mini hook 最多一个。
- 纯口播/无剪辑 → 去掉"大图—战术"视觉往返，改用"结论—原因—边界"的语言往返。
- 内容本身是清单 → 正文按清单写，但每点之间仍需一句衔接，否则会变成念稿。
- 脚本太长 → 先删"第二个点"，多数视频只需一个强点 + 一个佐证。

**输出**
- 五段式脚本（含每点衔接句）+ 节奏标注 + 结尾高音符。

**完成标准**
- 五步齐全且顺序正确；每个段落衔接都有 mini hook；结尾回收了开头痛点；通读无冗余句。

## B — 边界 (Boundary)

1. **证据等级：实践者（最低）。** 无控制实验、无样本量；「mini hook 提升留存」「结尾高音符提升互动」都是经验主张，需自己测。
2. **语域限制**：流程来自英文口播视频；中文的信息密度与句式不同，直译式衔接句会显得生硬，需改写而不是照搬。
3. **mini hook 用多了会疲劳**：每点都"但是下一个更重要"会让观众预感套路；一张片子最多 2–3 处。
4. **不适用场景**：新闻快讯、纯数据汇报、教学操作类内容，强行埋钩子会损伤信息效率。
5. **不承诺效果**：本卡只保证结构完整，不保证播放或完播；判定要回到 `video-metrics` 或自有 A/B 记录。
