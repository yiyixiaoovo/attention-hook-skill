# 视频留存度量：先量前 5 秒，再谈改法

## R — 原文

> engagement continuation rate (ECR), calculated as P (watch >5s), demonstrates stable behavior across different video durations.
> — short-video-engagement-2024.txt（Li et al., ECCV 2024, arXiv:2410.00289）

同文报告该指标与归一化平均观看比例的相关系数为 0.926（同一数据集内）。这是**相关**，不是干预效果。

## I — 方法论骨架

短视频的「开头好不好」不是感觉问题，是可以量的。拿到账号数据后按三步走：

1. **量开口**：取 **5 秒留存**（播放超过 5 秒的比例）作为「开头是否留住人」的读数。没有后台数据时，用公开数据的完播比例做代理，并显式标注「代理」。
2. **先归一化再比较**：跨视频、跨时长比较时用**观看比例**；原论文推荐 NAWP（按时长分桶归一化），不要用绝对观看秒数——时长本身就是协变量。
3. **给结论分级**：每条结论标 A/B/C 三级。A = 度量口径（可直接用）；B = 相关性（只作方向参考）；C = 广告证据（只界定问题，不外推）。**任何「改了会涨」的表述必须先降级为「与…同向」。**

三类常见误判：把 5 秒留存当点击率；用绝对观看时长比较不同长度的视频；拿广告投放的 hook 结论指导自然内容。

## A1 — 书中的应用

两篇来源都是建模/投放数据研究，没有叙事性案例。本批材料不含「某某改了开头后完播翻倍」这类案例，不得编造。

合成演练（非语料案例）：同一账号三条同品类视频，后台 5 秒留存相近，但按归一化观看比例排序与按绝对观看秒数排序结果相反。此时应采用比例口径，并检查「秒数更长的那条是不是本身就更长」。该演练只演示步骤，不产生效果证据。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `gap-design`（信息缺口）：那张卡决定**开头放什么**，本卡只负责**怎么量、怎么读**。先用 gap-design 产出开头，再用本卡验收；不要用本卡的相关系数反推内容结构。
- 与 `stickiness-pass`（黏性终检）：那张是发布前的表达自检；本卡是发布后的度量与归因。
- 与 `promise-integrity`（承诺兑现）：那张判断钩子与正文是否对得上；本卡不判断内容真伪，只判断数据口径。
- 与 `arousal-choice`（情绪选型）：两条证据链来源不同（JMR 转发 vs 视频平台留存），不可互相引用。

## E — 执行 (Execution)

**输入**
- 多条同品类短视频（条数须自定并记录）的：时长、平均观看时长、5 秒留存或完播比例、点赞数。
- 若无后台数据：公开可见的完播/进度数据，需标注为代理。

**步骤**
1. 归一化：观看比例 = 平均观看时长 ÷ 视频时长；若平台直接给 NAWP 类指标则直接用，并在表里注明口径。完成标准：每条视频都有归一化值与原始值。
2. 量开头：取 5 秒留存；缺失时用代理并标注。完成标准：每个数值都标了「实测 / 代理」。
3. 分级：给每条结论标 A/B/C。完成标准：没有一条结论是未分级的。
4. 反例对照：若有人主张「画质是主因」，要求「画质评分与互动量的相关证据」；该论文的对照发现二者相关很弱。完成标准：主张被要求证据，或被告知该反例。
5. 行业边界：跨品类模板一律不给「可直接用」的结论。完成标准：模板类建议都带「需同品类小样本验证」。

**分支**
- 账号没有后台数据 → 只能下 B/C 级判断，明确告知不能得因果结论。
- 5 秒留存低但整体观看比例不低 → 问题可能在中段，转 `stickiness-pass` 复查结构。
- 5 秒留存高但整体低 → 开头引人但没兑现，转 `promise-integrity`。
- 讨论涉及广告投放（CPI 类指标）→ 一律标 C 级，禁止外推到自然内容。

**输出**
- 一张指标表（归一化留存 / 5 秒留存 / 口径标注 / 结论分级）+ 一句「可下 / 不可下」的判定。

**完成标准**
- 每条结论都有 A/B/C 分级；所有「提升/涨」类表述已改为「与…同向」；没有把 5 秒留存当点击率；代理数据都有标注。

## B — 边界 (Boundary)

1. **单平台、相关性**：数据来自 Snapchat 短视频与 Meta 广告投放，均为观察/建模研究，不是随机对照实验。0.926 是同数据集内的相关，不能推出「改了就涨」。
2. **结果变量不同**：一篇测归一化观看比例，一篇测每次转化成本（CPI）。两者都不是「你账号的完播率」。
3. **广告证据不可外推**：前 3 秒 hooking period 的结论来自广告语境（v04 只到 reference 级），用它指导自然内容属于未验证迁移。
4. **反例保留**：视频质量评分（MOS）与互动量相关很弱（v03）——这削弱「画质是主因」的假设，但不证明画质无用。
5. **没有跨行业模板**：同一批 hook 特征在电商/医疗/快消的重要性排序不同（v05），照搬跨品类模板缺乏依据。
6. **阈值缺失**：「5 秒」是平台指标定义，不是创作规律；「留存多少算好」语料未给，**须自定基线**并记录。换平台必须重测。
