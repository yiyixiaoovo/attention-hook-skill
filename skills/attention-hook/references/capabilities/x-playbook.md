# X 平台发布与承接：选题、反差、折叠位、承接、分发

## R — 原文

> 先在爆帖评论区第一条挂上你最能打的代表作，路人翻评论时顺脚就能进主页。
> — x-playbook-author-2026.txt（作者本人经验，2026-11-25 提供）

**这张卡不是证据卡。** 内容来自一位作者的 n=1 经验（该帖约 150 万曝光、作者称 90k 转化、当时约 2000 粉，数据未经独立核实）；
其中的平台机制说法（「显示更多增加权重」「算法精准推荐」「转帖权重高于评论」）**无公开依据**，B 段会逐条列明。

## I — 方法论骨架

X 上一条帖子的生命周期分两段：**发出去之前**决定它能不能被点开，**发出之后 10 分钟**决定流量能不能留下来。

**发布前，五件事按顺序过：**

1. **选题**：先定这条是打泛流量还是垂直人群；找赛道里最近在聊的事；**换一个别人没讲过的角度**（重复复述没有意义）。
2. **一眼看懂**：读者不需要你解释背景就能看懂第一句。
3. **钩子**：第一句必须让人有理由读第二句；不一定要标题党，一句让人愣一下的话就够。
4. **反差**：越荒诞的事越要一本正经地写——先给「这是正经新闻」的预期，再把反转甩出来；先埋线，后甩包袱。
5. **形态**：一行一句、行间空一行；按受众所在时区选发布时间。

**发布后，十分钟内做三件承接：**

6. 自己评论区第一条挂上最能打的代表作（路人翻评论时顺脚进主页）；
7. 简介改成人话，说清「我平时写什么」；
8. 置顶换成与这条最相关的一篇。

**贯穿全流程的一条**：AI 只做润色，人必须自己再改一遍；把通用动词换成具体动作或圈内说法，保住「人味儿」。

## A1 — 书中的应用

来源是作者本人一条爆帖（作者称约 150 万曝光、90k 转化、账号当时约 2000 粉；**未独立核实**）。原文举的例子：
「黄仁勋今天正式回英伟达办公」——9:00 还是正经的「恢复 CEO 职务」，9:05 突然拐进「月球算力基地」，用严肃新闻语体把反差做出来。

这只是单一作者的单一案例，不是可复现的因果证据；它的价值在**操作顺序**，不在数据。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `hook-craft`（钩子打磨）：那张卡管**内容结构**（六槽/三拍/四错），本卡管**平台动作**（选题角度、折叠位、承接、时区）。先过 hook-craft，再过本卡。
- 与 `distribution-first`（渠道）：那张卡回答「发哪个平台、优化打开还是转发」；本卡是**已确定在 X 发**之后的具体操作。
- 与 `promise-integrity`（承诺）：本卡的「一本正经写荒诞」只适用于**明确是段子/演绎**的内容；涉及真实人物、真实事件时不得使用，否则就是误导。
- 与 `video-metrics` / `stickiness-pass`：本卡不提供任何效果保证；发布后用 `stickiness-pass` 的 A/B 记录表自己的基线。
- 与 `story`（叙事）：故事是体裁决策；本卡的「埋线—甩包袱」是段落安排技巧，两者可叠加。

## E — 执行 (Execution)

**输入**
- 一条写好的帖子草稿（或选题 + 赛道 + 目标人群）。
- 账号当前的简介、置顶、最能打的代表作链接。

**步骤（发布前）**
1. 定赛道与受众：写一句「这条给谁看、属于泛流量还是垂直」。完成标准：写不出这句就不发。
2. 换角度：对同一热点列 5 个角度，划掉大家都在说的，只留 1 个。完成标准：能说出「别人没讲过的点是什么」。
3. 第一句测试：只读第一句，判断「有没有必须读第二句的理由」。完成标准：第一句不依赖背景解释也能看懂。
4. 反差设计（如适用）：确定埋线句与甩包袱句，语体保持一致。完成标准：埋线不提前泄底，包袱落在读者没预料到的一句。
5. 排版与时区：一行一句、行间空行；按受众主要所在时区定时。完成标准：手机上一屏能读完钩子，且时间对得上受众活跃段。

**步骤（发布后 10 分钟内）**
6. 评论区首条挂代表作；7. 改简介；8. 换置顶。完成标准：三件事都有截图或确认记录。

**分支**
- 内容涉及真实人物/事件 → 禁用「一本正经写荒诞」，改用证据与克制的表述（转 `promise-integrity`）。
- 账号 0–1 阶段、没有「代表作」→ 评论区首条改放「本系列的其他篇」或置顶串，不要挂空链接。
- 目标是转化而非涨粉 → 把简介改成「我能提供什么」，而不是「我写什么」。
- 不确定平台机制（折叠位、权重）→ 当成假设做小样本对照，不要写进对外承诺。
- AI 辅助 → 只做润色，禁止直接生成后发布；发布前必须人工通读一遍。

**输出**
- 帖子终稿 + 发布检查单（赛道/角度/第一句/排版/时间）+ 发布后承接三件事的执行记录。

**完成标准**
- 发布前五项全部有明确结论；发布后三件承接在 10 分钟内完成；没有任何未经证实的平台机制承诺写进正文。

## B — 边界 (Boundary)

1. **证据等级：实践者（最低）。** 单一作者、n=1 案例；「150 万曝光 / 90k 转化 / 2000 粉」均为作者自述，**未经独立核实**，且「90k」的口径（曝光？主页访问？涨粉？）原文未定义。
2. **三条平台机制说法无公开依据**，不得当作事实转述：
   - "把内容留在「显示更多」之后会增加权重、让系统推流"（xp08）
   - "算法会精准推荐给能看懂的人"（xp06）
   - "转帖权重比评论高"（xp09）
   这些可以当**假设**去自测，不能当承诺写给读者。
3. **与「一眼看懂」的张力**：把钩子留在第一屏、包袱放到折叠后，和「读者不用解释背景就能看懂」在信息密度上冲突；两者都重要时，优先保证第一句可理解，再谈折叠。
4. **X 专属**：折叠位、转帖、时区这些操作依赖 X 的产品形态；换平台（公众号、小红书、视频号）需重测。
5. **伦理红线**：「一本正经写荒诞」只用于明确的段子/演绎；真实人物与事件不得用反差包装，否则触及 `promise-integrity` 的标题党边界。
6. **不承诺效果**：本卡不提供任何「照做就能爆」的保证；爆款方差极大（同作者同体系下也可能差十倍），流量承接只能提高转化效率，不能制造流量。
