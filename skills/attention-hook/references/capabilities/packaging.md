# 包装：标题、封面、开场三件套（实践者体系）

## R — 原文

> It's frustrating, but YouTube, the video platform, is actually a packaging game because the best-in-class click-through rates are like 10 to 12%.
> — kallaway-transcripts-2026.txt（practitioner）

**这张卡不是证据卡。** 内容来自一位创作者的公开视频经验，没有控制实验；10–12% 是 YouTube 的经验数值，不是普适规律。

## I — 方法论骨架

包装不是"起个标题"，是**在写内容之前**决定别人会不会点进来、以及点进来后会不会留下。

1. **先包装，后内容**：先定标题与封面，再写脚本（原文把 packaging 排在五步第一位）。
2. **标题与封面互补**：一个负责给结果/痛点，另一个负责给画面/情绪；两者不要重复同一个信息。
3. **标题要能"钓"到点击**：用受众想要的结果或痛点来写；但只钓它能在内容里兑现的东西。
4. **开场确认点击**：前几秒必须让人确认"我点对了"——内容是标题承诺的兑现，不是另一个话题。
5. **接受点击率的现实**：顶尖水平也只有约 10–12%，意味着 9 成人会划走。包装的任务是**提高比例**，不是追求人人都点。
6. **人群匹配（假设）**：把内容持续给同一批人看，帮助系统把内容推给对的人；这条是实践者观察，不是平台规则。

## A1 — 书中的应用

来源是创作者本人频道的经验，没有可引用的叙事案例。本批材料不含"换标题后播放翻倍"这类数据，不得编造。

合成演练（非语料案例）：一条讲「本地大模型」的视频，原包装是「本地部署教程」。按三件套改：标题「8GB 旧笔记本也能跑 14B 模型」；封面用「旧笔记本 + 14B 字样 + 惊讶表情」，与标题情绪一致；开场 3 秒直接展示跑起来的画面并说「这就是那台五年前的机器」。该演练只演示流程，不产生效果证据。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `distribution-first`：那张卡决定**发哪个平台、优化打开还是转发**；本卡是平台已定后、内容写出前的包装设计。
- 与 `script-flow`：本卡在**最前面**（包装先行），那张卡接手写整篇脚本。
- 与 `hook-craft`：本卡管标题/封面/开场确认，那张卡管开头几句话的结构与诊断；两者可叠加，但本卡更早。
- 与 `promise-integrity`：本卡的「钓点击」必须接受那张卡的兑现约束；钓一个兑现不了的承诺就是标题党。
- 与 `video-metrics`：本卡不提供效果承诺；发布后用那张卡的指标判定。

## E — 执行 (Execution)

**输入**
- 选题 + 目标人群 + 内容真正能兑现的结论（一句话）。
- 可选：同赛道高播放视频的标题与封面样本。

**步骤**
1. 写内容能兑现的那一句。完成标准：这句话没有形容词堆砌，且内容里确实有对应部分。
2. 写标题：围绕受众结果或痛点，长度控制在一眼扫完。完成标准：标题里的承诺能在第 1 步那句话里找到。
3. 做封面：与标题互补（标题给结果、封面给画面/情绪），表情或情绪与标题语气一致。完成标准：遮住标题看图、遮住图读标题，两边都不重复且都成立。
4. 写开场确认：前 3–5 秒复述标题承诺并给出第一个证据。完成标准：开场没有跑题，且没有把最精彩部分一次讲完。
5. 一致性检查：标题—封面—开场是否指向同一件事；承诺是否在正文兑现。完成标准：三处指向同一结论；兑现位置明确。
6. 记录基线：发布前记下当前账号同类内容的点击率/播放中位数。完成标准：有可比基线，便于事后判断。

**分支**
- 内容偏教育/工具 → 标题给结果，封面给"前后对比"或"具体物件"。
- 内容偏娱乐/观点 → 封面给情绪或冲突画面，标题给立场。
- 标题写得很炸但内容兑现不了 → 回到 `promise-integrity` 删承诺或补内容，不要只改封面。
- 没有封面制作能力 → 退化为"纯文字标题 + 开场确认"，不要用无关网图。
- 新账号没有基线 → 先发 10 条记录中位数，再谈优化。

**输出**
- 标题、封面方案、开场 3–5 秒台词，以及三者一致性检查结论。

**完成标准**
- 三件套都指向同一兑现点；标题承诺在正文有明确落点；有发布前基线；没有无法兑现的钩子。

## B — 边界 (Boundary)

1. **证据等级：实践者（最低）。** 全部来自一位创作者的视频经验；10–12% 的点击率是 YouTube 经验值，不同平台、品类、账号阶段差异很大，不能当目标写死。
2. **「bait a click」与欺骗的边界**：钓点击指"把真实价值说清楚以换取点击"，不是"承诺内容里没有的东西"。后者归 `promise-integrity` 处理。
3. **平台差异**：标题长度、封面比例、是否展示封面（如纯文字平台）都不同；换平台需重做，不能照搬。
4. **人群匹配是未验证假设**：原文说"帮助算法找到对的人"，这是实践者观察，不是平台公开机制；可以当实验假设，不能当承诺。
5. **不承诺效果**：本卡只提高"点开与留下"的结构合理性，不保证流量；同账号同体系下播放量方差仍可能很大。
