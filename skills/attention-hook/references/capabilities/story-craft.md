# 故事技法：用问题、张力与分层释放把人留住

## R — 原文

> The bigger and more non-obvious the question, the bigger the curiosity, the higher the stakes, and the more dopamine that gets released.
> — kallaway-transcripts-2026.txt（practitioner）

**这张卡不是证据卡。** 它讲"怎么搭故事"，不讲"故事有多大效果"——后者在 `story` 卡（有元分析证据与边界）。

## I — 方法论骨架

故事的作用是**持续释放好奇**，不是"讲一个完整的事"。四个操作：

1. **问题要够大、够不显眼**：越大的问题、越不显然的答案，张力越高（原文把"问题的规模与非显然性"直接和利害、多巴胺挂钩）。
2. **分层释放（多巴胺阶梯）**：不要一次给完答案；把信息切成一层层，每层解开一点、再抛一个新问题。
3. **利害要落在观众身上**：故事里的代价必须与观众相关，否则只是别人的事。
4. **六层结构**：原文提到一个「六层」的递进结构（从"有点兴趣"到"非看不可"），但本批字幕没有完整提取出六层的名目，**不要编造层级名称**。

与 `story` 卡的分工：`story` 回答"故事 vs 说明文哪个更好记"（有证据、有边界）；本卡回答"一条故事型内容怎么搭"（无证据、纯操作）。

## A1 — 书中的应用

来源是创作者自己的视频，没有可引用的案例。本批材料不含叙事实验数据。

合成演练（非语料案例）：一条讲「为什么你的 AI 助手总答错」的视频，按技法搭：先抛一个够大且不显眼的问题（「不是模型笨，是你问法触发了一个隐藏机制」）；第一层给现象（同一个问题换个问法答案就变）；第二层给机制；第三层给边界（什么情况下这招失效）；结尾回收「不是模型笨」。该演练只演示结构，不产生效果证据。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `story`（证据卡）：那张卡决定**该不该用叙事**（目标匹配、边界、发表偏倚），本卡决定**怎么搭叙事**。先用 `story` 做体裁决策，再用本卡写。
- 与 `hook-craft`：那张卡管开场几句的结构；本卡管整条故事的张力曲线。
- 与 `script-flow`：本卡是内容层（故事怎么讲），那张是工程层（五步流程怎么走）。
- 与 `surprise-contrast`：那张卡的"预期违背"是奇观式反差；本卡是**延迟满足式**悬念，靠分层而非一次性反转。
- 与 `promise-integrity`：分层释放不等于故意拖时间；每一层都要有实质信息，否则就是标题党。

## E — 执行 (Execution)

**输入**
- 一个真实的核心信息（一句话）。
- 目标受众与他们关心的问题。
- 可用素材：案例、数据、过程记录（至少一项）。

**步骤**
1. 写问题：把核心信息改写成一个"够大且不显眼"的问题。完成标准：这个问题不是常识题，且答案不在问题里。
2. 定利害：写清"如果不知道这件事，观众会付出什么代价"。完成标准：代价与观众自身相关，不是创作者自己的事。
3. 分层：把答案切成 2–4 层，每层只解开一部分，层与层之间留一个新问题。完成标准：每层都有实质信息，删掉任何一层故事就不完整。
4. 排顺序：先给最容易共鸣的现象，再给机制，最后给边界/例外。完成标准：顺序不是"研究顺序"，而是"观众理解顺序"。
5. 回收：结尾回到第 1 步的问题，确认它被回答了。完成标准：开头的问题在结尾有明确对应。
6. 真实性检查：所有人物/事件是否真实；虚构是否标注。完成标准：无未标注的虚构情节。

**分支**
- 没有真实案例 → 用"过程记录/数据"代替故事，不要编人物。
- 内容太短（<60 秒）→ 只保留"一个问题 + 两层"。
- 问题太大、内容撑不住 → 缩小问题，别用分层掩盖信息量不足。
- 观众是专业同行 → 减少铺垫层，直接给机制与边界。

**输出**
- 问题句 + 利害句 + 2–4 层结构 + 回收句 + 真实性标注。

**完成标准**
- 问题够大且不显眼；每层有实质信息；利害落在观众身上；结尾回收问题；虚构已标注。

## B — 边界 (Boundary)

1. **证据等级：实践者（最低）。** 无对照实验；"多巴胺""六层"等说法是创作者的概念框架，不是神经科学结论。**不要把它写成科学证据**。
2. **六层名目未完整提取**：字幕里只有"六层"的提法与部分描述，本卡不编造层级名称；需要时回看原视频核实。
3. **与元分析证据的关系**：`story` 卡的元分析只支持"故事更好懂好记"，不支持"分层释放更易传播"；两层证据不可混用。
4. **伦理**：分层释放不是故意拖延或制造焦虑；每层必须推进理解，否则接近标题党。涉及真实人物时不得虚构情节。
5. **语言与平台**：技法来自英文口播；中文书面内容的"分层"节奏更快，层数应减少。
6. **不承诺效果**：本卡只提供结构，不保证完播或转发。
