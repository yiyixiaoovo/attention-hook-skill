# 钩子打磨：六槽、三拍、四错、四通道（实践者体系）

## R — 原文

> The viewer starts the video believing one thing, and then we introduce an alternative. They believe A, we show them B, and the distance between A and B is contrast.
> — kallaway-secondary-2026.txt（Kallaway 主张，经 BuildOS 二手分析转述）

**这张卡不是证据卡。** 它记录一套实践者的操作流程；原视频与分析页都没有给出控制实验、样本量或提升数据，
示例均为其本人选出的成功视频（存在幸存者偏差）。它只能用于「怎么写、怎么查」，不能用于「能提升多少」。

## I — 方法论骨架

五件工具，按顺序用在一个钩子上：

1. **三拍搭骨架**：Context Lean（把话题说清，让错的人离开）→ Scroll-Stop（用「但是/然而」制造停顿）→ Contrarian Snapback（反向急转，仍留在话题上）。
2. **六槽做体检**：Subject（谁）、Action（做了什么）、Objective（得到什么结果）、Contrast（翻转了什么）四项必填；Proof（凭什么信你）、Time（多快）可选。缺槽就补，不是笼统「写得更抓人」。
3. **四错做诊断**：Delay（话题出现太晚）、Confusion（看不懂）、Irrelevance（与我无关）、Disinterest（看懂了但不好奇）。按这个顺序逐项修。
4. **六原型选题**：Fortune Teller（未来）、Experimenter（实测）、Teacher（教你）、Magician（纯视觉冲击）、Investigator（秘密）、Contrarian（反常识）。**按手上有什么画面挑，不按选题挑**；Magician 只能叠在别的原型上当修饰层。
5. **四通道对齐**：视觉、口播、屏幕文字、音频必须指向同一件事；视觉是承重件，文字负责铺垫与确认。
6. **表达层对齐**：画面里人物的**面部表情要与标题/口播的情绪一致**（原文："The emotion on your face in the image matters a ton"）。观众先读表情，再读文字；两者打架会让人出戏。
7. **AI 只做清晰化**：把已写好的钩子交给 AI 做"同义改写、降到六年级阅读水平、不许改意思"，**不要从空白生成钩子**。原文给的是固定 prompt（"I've written a hook for… I want the meaning to be the exact same…"），流程是：人写 → AI 改清晰 → 人再定稿。

核心判据：**A（受众现状信念）与 B（你的替代）的距离就是对比**；只写 B 而受众没有共享基线，钩子就会落空。

## A1 — 书中的应用

原始材料是实践者视频与二手拆解，没有叙事性案例可引用。分析页转述的例子（Sphere 视频三拍、六原型的背包示例）
均为**其本人挑选的成功案例**，不能当作因果证据。

合成演练（非语料案例）：一条讲「本地大模型」的中文短视频，原钩子是「今天聊聊本地部署」（无对比、无目标）。
按流程重写：Lean「8GB 显存的旧笔记本，也能跑 14B 模型」→ Stop「但这还不是最离谱的」→ Snapback「最离谱的是，它比云端还快」。
再查六槽：Subject=旧笔记本、Action=跑、Objective=14B 模型、Contrast=旧硬件 vs 大模型；Proof 可放第二句（实测数据）。该演练只演示流程，不产生效果证据。

## A2 — 与相邻能力的区分 (Adjacent)

- 与 `gap-design`（信息缺口）：那张卡回答**为什么**会有好奇心（缺口/信息差，有综述证据）；本卡回答**怎么写出**一个钩子（流程，无实验证据）。本卡更偏句式与诊断，**证据等级低于**那张卡；冲突时以 `gap-design` 的机制为准。
- 与 `concretize`（具体化）：那张卡修「句子太虚」；本卡的 Confusion 只做诊断，具体改写交给 `concretize`。
- 与 `surprise-contrast`（预期违背）：那张卡讲「相关但没预期」（有综述支持）；本卡的 Contrast 是实践操作（A→B 明说或隐含），两者可叠加。
- 与 `promise-integrity`（承诺兑现）：本卡的反模式「空 snapback 没有兑现」正是那张卡的边界；本卡给句式，那张卡给底线。
- 与 `video-metrics`（留存度量）：本卡只产出候选，**效果必须由那张卡的度量流程验证**；不得用本卡的流程宣称提升留存。
- 与 `packaging`：那张卡在内容之前定标题/封面/开场承诺；本卡打磨开场几句话。先 packaging，后 hook-craft。
- 与 `script-flow`：那张卡管整篇五步结构；本卡只管开头。本卡产出的钩子要能接进那张卡的"开场"一步。
- 与 `story-craft`：那张卡管故事张力曲线；本卡管开头三句。故事型视频可先过 story-craft 再回本卡检查开头。

## E — 执行 (Execution)

**输入**
- 一条已有钩子（第一句/前 3 秒脚本），或一个选题 + 手上可用的画面清单。
- 平台与时长（短视频 / 长视频 / 图文）。

**步骤**
1. 三拍重写：写出 Lean / Stop / Snapback 三句。完成标准：三句都在，且 Stop 以转折词开头，Snapback 与 Lean 方向相反、但仍在话题内。
2. 六槽体检：逐槽标注，缺哪个补哪个。完成标准：四项必填槽都有对应文字，Proof/Time 标「用 / 不用 + 理由」。
3. 四错诊断：Delay / Confusion / Irrelevance / Disinterest 逐项判定。完成标准：四项都有「通过 / 不通过 + 位置」；不通过项给出改法。
4. 原型选型（视频场景）：对照六原型，按可用画面选一个，Magician 只能叠加。完成标准：写明所选原型与所依赖的画面；画面弱则明确「不做这条」。
5. 四通道对齐（视频场景）：列出视觉/口播/文字/音频各说了什么。完成标准：四者指向同一对象；有冲突则删改。
6. 落地验证：把最终钩子交给 `video-metrics` 的度量流程或 A/B 记录表。完成标准：没有把本卡当效果证据；至少有一个可观测指标。

**分支**
- 纯图文（无画面）→ 跳过第 4、5 步，只做三拍 + 六槽 + 四错；Magician 不可用。
- 教育/知识内容 → Proof 槽按近必填处理；娱乐内容 → 不强行加 Proof。
- 受众基线不确定 → 用**明说对比**（A 与 B 都讲出来）；基线明确才用隐含对比。
- 钩子与正文兑现不了 → 回到 `promise-integrity`，删钩子或补兑现，不要只改句式。
- 画面很弱 → 按实践者主张应「不做这条视频」；这条是经验判断，不是证据。

**输出**
- 三拍稿 + 六槽标注 + 四错诊断表 +（视频）原型与四通道对齐表。

**完成标准**
- 三拍与六槽齐全；四错逐项判定过；视频场景做了原型与四通道检查；结论里没有「提升多少」类承诺；效果验证已被指派。

## B — 边界 (Boundary)

1. **证据等级：实践者（最低）。** 全部内容来自 Kallaway 的视频主张与二手拆解，**0 控制实验、0 样本量、0 提升数据**；示例为幸存者样本。这是本套技能里唯一一张明确标为「非证据」的卡。
2. **「scientifically impossible to skip」是营销话术**，不是研究结论；不得转述为科学结论。
3. **语域与平台限制**：体系来自英文短视频；中文的语序、信息密度、口播节奏不同，直译句式可能变长变绕；长视频与图文需重测。
4. **四通道里的「视觉承重」无法在纯文本场景验证**；图文作者只取三拍与六槽，不要假装有视觉证据。
5. **AI 使用边界**：实践者本人只用 AI 做清晰化改写（六年级阅读水平、同义不改意），**不从空白生成钩子**；把本卡交给模型「批量生成 100 条」会得到结构正确但没有洞察的内容。
6. **与实证卡冲突时**：机制问题以 `gap-design`（Kidd & Hayden 综述）为准；效果问题以 `video-metrics` 的度量为准。本卡不提供任何因果承诺。
