# attention-hook

A distilled skill set for **writing openers, titles and hooks** for articles and short videos —
and for knowing **when a hook is a lie**.

Compiled from five sources: Kidd & Hayden (2015) on curiosity, Berger & Milkman (2012, JMR) on
virality, a meta-analysis on narrative memory (Mar et al., 2021, CC BY), two open-access papers on
short-video engagement, plus two clearly-labelled practitioner collections.

## What is inside

- **18 capabilities**, compiled from one Capability Bundle into a single entry skill.
- **9 evidence-backed cards** (papers / meta-analyses) and **9 practitioner cards** (hook craft, X
  playbook, packaging, script flow, story craft, audience psychology, content business,
  platform-native specs, hook forensics).
- Each card carries an evidence boundary section; practitioner cards state **0 controlled
  experiments** and never promise lift.
- **162 trigger-evaluation cases** (9 per capability) with `minimum_pass_rate: 0.8`, plus
  **24 behavior-eval cases** (72 must-appear checks) for the core cards.

## Effect loop

- `stickiness-pass` ships an A/B log template (numbers).
- `knowledge-base/` records **conclusions and limitations** (pre-registered hypotheses, four-level verdicts: supports / contradicts / inconclusive / invalid). Its `INDEX.md` is generated by `scripts/kb_index.py` and checked in CI.
- `scripts/build_packs.py` builds install bundles: **starter** (8 cards), **practitioner** (9), **full** (18), as zips with a sha256 manifest, plus a Claude Code plugin package.

## Install

Copy the compiled single-skill directory into your skills folder:

```powershell
# from the cangjie-skill repo root
python scripts/cangjie.py compile --bundle books/attention-hook/.cangjie/capabilities `
  --out dist/attention-hook-single --output single --yes --strict
Copy-Item dist/attention-hook-single "$env:USERPROFILE\.dsh\skills\attention-hook" -Recurse
```

Then just ask: "tighten this opening", "why is this hook flat", "how do I measure first-5-second
retention", "is this title clickbait".

## Evidence policy

- Every card's **B section** states what the evidence does *not* support.
- Strong sources (meta-analysis, peer-reviewed) and practitioner heuristics are **never mixed
  silently**.
- Practical effect must be measured on your own account: see `stickiness-pass` (A/B log) and
  `video-metrics` (retention metrics).
